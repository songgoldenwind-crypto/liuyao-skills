# 病药、调神与条件策划

## 1. 术语

- 病：对当前体用造成损害的失衡状态，也可指受损部位。病可能落在某卦、某爻、六神、象或组合上。
- 致病点：造成该损害的来源。病与致病点应分栏，不混写，例如“卯受破”为病，“酉冲卯”为致病链。
- 损神：在当前条件下造成损害的因素。
- 药、调神：当前最能改善体用及全局失衡的因素。这里的调神与代表所测对象的用神不是同一概念。
- 病药均为术数内部术语，不是医学诊断或药品处方。

## 2. 取调神流程

1. 先固定本次体用，再评估全五行的真实旺弱，方法见 `03-strength-balance.md`。
2. 从本、互、变与行运的全局查关键受损点：过旺过弱、源头受阻、生克失衡、冲破、合绊、墓绝、刑害等。
3. 分开列出病、致病来源、可能后果；可在每个环节立太极点追踪人物、地点、事情。
4. 在相关五行、八卦、十二支、六神与行运中逐项比较候选药，不只找表面相生者。
5. 为每个候选写明：改善哪一环、通过何种生克冲合关系、是否伤体伤用、是否带来新的墓刑害或合绊、是否有力到位。
6. 选一至两个对全局影响最大的候选作为主线，其他只作辅助。选不出有效候选时，明确“当前无可用调神”，不强凑方案。
7. 追踪调神自身的原、忌、仇、泄及双原，检查其能否持续作用。
8. 把候选放入拟议时间、地点、人事条件重新演算。条件变，病药重新取。

## 3. 取法及限制

| 条件 | 取法 | 判断要求 |
|---|---|---|
| 本体偏弱且可扶 | 扶抑中的扶 | 找有效生扶；伤其扶者也是病 |
| 本体过强且可抑 | 扶抑中的抑 | 找有效克泄；伤其抑者也是病 |
| 两方对峙、争克或气势阻塞 | 通关 | 使强方之气流向中介，再生弱方；核验中介有力 |
| 季令、组合呈过寒或过燥 | 调候 | 在本体系中检查水火调节；不据此判断真实体温或健康 |
| 一方专旺，气势不可逆，弱方无力自立 | 从强、从势、顺势 | 不强行扶弱克强；机械取调反可能增添冲突 |

- 通关常可先比较，但不绝对优于制衡。能在特定条件下改善全局的冲、克、合、刑等，也可以是药。
- 需要生时生为益，不宜生时生也可为害；需要克时克为益，不宜克时克为害。
- 不固定把白虎、兄弟、忌神看成凶，也不固定把青龙、财生官看成吉。必须说明其对当前病药的作用。
- “取药”中的医疗比喻不能转成现实服药、注射、饮食疗法或外科操作。

## 4. 药效条件与副作用检查

- 有调神但休囚、受制、被合走、伏而不出 → 可能有名无用或暂时无用。
- 调神存在但不足以持衡 → 病重药轻；说明尚缺何种力量或时机。
- 调神过强，扶抑过度 → 药可能成病，重新选取。
- 调神缓解一处却制造另一处冲刑墓害 → 标明“需调又怕调”，分别列收益和副作用。
- 天时到位、地点不合，或地点合而时机未到 → 只能判部分条件满足，不能直接判成。
- 特强从强、过弱从势 → 可能不宜调、调无用或调反生事；按整体气势判断。
- 每一阶段的调神只对该阶段有效，进入新的年、月、日、时或事件阶段必须复核。

## 5. 应期接口

以“病何时加重、药何时到位、药何时失效”形成应期候选，再与爻动静、空破、进退、墓合等规则交叉核验：

| 条件 | 应期候选 |
|---|---|
| 动爻旺相 | 值、合 |
| 进退 | 值、冲、合 |
| 忌神值事 | 不利候选；若被冲克墓绝，须再看其是否还能作用 |
| 休囚、绝 | 生旺 |
| 爻多太旺 | 库藏 |
| 入墓、逢合 | 冲开 |
| 静、空 | 值、冲 |
| 冲破 | 合、填实 |
| 长生 | 长生时 |

这些是候选筛选，不能省略真实强弱及组合。根据实际办事时段排除不相关候选；不能把某一例不考虑夜半的做法写成所有人的作息规则。不同链条同时指向一个时段时，可提高其优先级，但不声称必然应验。

## 6. 候选药比较示例

### 财寅空破、财源子水月破

条件：世官午较强，兄申动化父未冲克财寅，子水伏且月破。

- 子水本可生财，但当前月破 → 暂难直接为药。
- 未合午，可减午冲子，但又可能使寅入墓、克害子 → 有副作用，不能只取“合午”。
- 巳合申，可减少冲寅，但又涉及刑、泄财 → 不能只取“合申”。
- 寅填实可缓解破，但自身弱、源不足 → 持续性不足。
- 亥合寅且水生木，又可助水源 → 作为较优候选，再核验能否助成申子辰局及生世。
- 戌合寅午、构成火局生官 → 另一候选，按全局比较。

限制：不可把卦中关系转换为保证求婚成功的方案；对象意愿属于真实必要条件。

### 酉世受卯冲、巳克，辰可生合酉

条件：辰初为缓解酉破的药。

判断：辰同时有网、困的象时，可兼有庇护与束缚两义；当事件阶段变化，辰可由药转病，后又回到生计支持。酉填实或戌冲辰是重新考察的条件。

限制：示例原有远期应期与事后反馈不一致，不能拿来当作准确日期验证；不据此推定拘押、定罪、死亡或现实法律结果。

### 财旺而源合、世空

条件：财戌世旺空，财源子午逢日月未合而不动。

- 世空为一病 → 戌值、辰冲是候选。
- 财源被合为主要病 → 子冲午、丑冲未，分别检查解合路径。
- 土财过旺 → 申金泄土可作全局候选。
- 申月可能启动，酉合辰又可能妨碍辰冲戌，戌月填实后再遇亥子克破午 → 应分段判断，不能把一段的药推成全年皆宜。

限制：示例只记录与当事人计划相合，没有完整后验；不据此承诺脱货、回款或盈利。

### 子水可解局，却伏弱受制

条件：金强克木，子水理论上可泄金生木，但子水伏于未下、休囚，又受丑合克或辰动克墓。

判断：将“水能通关”与“水实际能用”分开；有通关路径不等于现有通关力量。乾宫初爻子水还可参考“潜龙勿用”，作为药暂不可用的附加象。

限制：材料有“凡乾宫以子水为调基本无用或暂时无用”的概括，但同时给出水弱、伏藏、被制等具体条件；故只保留为该条件组合下的规则，不把所有乾宫子水永久判无用。

### 冲起可用的静爻或空爻

条件：世父戌需官火来生，官午空、官巳静；子水本可冲午，却被辰制墓而无力。

判断：不能硬用子水；可另查亥冲巳，令官火有机会作用于世。随后检查亥自身强弱及其他副作用。逢申迎运、财化进等可作后续条件，不能单凭“缺水”就保证开业盈利。

### 暂缓冲突与持续通关分开

条件：戌土旺克亥水，卯可合戌，申酉可泄土生水。

判断：卯合戌可作为暂缓的候选；申酉泄土生水可作为持续补弱的候选。先看当令是否支持，再看药是否引出其他冲克，不能因为有“金击木”之象就提出伤人方案。

## 7. 策划只在用户需要时展开

先给卦理判断与成立条件；需要策划时，再把药映射到天、地、人、事四项：

- 天：筛选调神有效时段，避开病与致病力量明显加强的时段，并核对现实日程。
- 地：候选方向、位置或环境应与调神一致，且不产生新的冲克。一个大方位内也要细分支位。
- 人：六亲所指关系可作帮助对象的假设，例如父母爻为药可考虑长辈或有经验者；现实合作以能力、意愿和事实为据。
- 事：找当前可执行的具体行动。沟通不当则改善沟通，项目条件不足则补条件，有现实纠纷则依法处理，不能把符号当作现实致因已经查实。

条件：西北亥能冲动巳使其生世，但西北戌又会冲破辰世。

判断：保留“避戌取亥”的细分，不笼统写“西北均吉”。原例把亥与戌同归西北仅是大方向归类，不表示亥支就是戌支。

## 8. 可选象征映射

以下仅为本体系的象征对应，可在用户明确想要传统象征性布置时使用。它们不构成现实疗效、招财、免灾或改变他人意愿的保证。

| 药五行 | 主要方位与卦 | 色彩、静物示意 |
|---|---|---|
| 金 | 乾兑，西北与西；兼查坤艮生金 | 白色、圆形、普通金属物件 |
| 木 | 震巽，东与东南 | 绿色、花草、木制品 |
| 水 | 坎、亥子，北；个例兼西北 | 黑色、水景图 |
| 火 | 离，南；个例兼东南 | 红色、普通灯光、字画 |
| 土 | 坤艮，西南与东北 | 黄色、稳定摆放的小山石造型 |

- 支象：寅可取虎形、植物，卯兔形，辰龙形，巳蛇形，午马形，申猴形，酉鸡形，戌狗形，亥子水象；仅按相关卦局所需选静态图案，不要求饲养、伤害或放生动物。
- 六亲象：父母可对应文书或金锁意象，子孙可对应佛像意象，财可对应古钱意象；是否采用依用户文化偏好。
- 六神可用同名意象，但白虎可为药、青龙可为病，不能按吉神凶神固定选物。
- 数象可按已明确的卦数爻数配数。现有示例用乾一、兑二、离三、坤八，以及“六兼金水”；没有给出统一数制，不能把不同数制混成通用公式。
- 文字象可用药支或相应字作提醒；不得声称符咒有已证实的驱灾作用。
- 所置物有阶段性：病药变，原先选择需重审。不能把一次取药变成终身固定配色或方位禁忌。

## 9. 不输出为行动处方的内容

- 不输出饮蛇血、按生肖忌口或进补、以五行缺水判断人体缺水等医疗饮食处方；现实疾病、营养和用药依医疗判断。
- 不输出杀动物破煞、让动物代灾、持续养到死亡、放生等操作。
- 不输出埋刀、挂锤以伤敌、动武、用仪式造成他人伤亡等建议；现实威胁优先采用避险、留证、报警等合法方式。
- 不用姓名偏旁、属相、性别或一次卦象断定现实人格和可信度。
- 不把临床职业“见刑伤”转述为希望他人患病；此类只能保留为职业语境会改变象义的例子。
- 不输出断死、必受刑、可保平安、必盈利等保证。无药或药弱只表示该术数解释中缺少解法，不表示现实无解。

## 10. 输出字段

`体用 → 强弱依据 → 病 → 致病链 → 候选调神及副作用 → 当前是否到位 → 适用时段与失效条件 → 所问事项结论`。

需要策划时加：`现实可行动项 → 可选象征项 → 不能从卦象确定的部分`。没有询问策划时不展开置物、配色等内容。
