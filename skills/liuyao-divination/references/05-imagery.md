# 卦名、卦象与爻象

## 使用顺序

1. 先定所问之事与太极点，分体用，分析五行力量及病药。
2. 确定主要矛盾、帮助或损伤体用的关系后，再把六亲、六神、卦名、爻位、地支等翻译成具体象。
3. 将时间条件加入已有关系，判断何时关系可能成立、减弱或解除。
4. 最后按需要补卦爻辞与神煞，不逐项堆砌全部象义。

条件：主要矛盾尚未明确。→ 判断：停留在体用、五行、生克制化分析。→ 限制：不要先编具体人事再倒找卦象。

条件：同一关系对不同对象作用不同。→ 判断：分别列有利与不利，允许吉中有凶、凶中有吉。→ 限制：不可把某爻对某对象有利概括为全卦全方面吉利。

## 候选收束

候选象义按以下顺序筛选：用户已经提供的现实背景；与事用、人用的直接关系；有作用权的动变与强弱；爻位、卦名、六神和神煞辅助。前一层已经能确定现实类别时，后一层只补性质，不另造平行故事。

默认只输出证据最强、与所问最贴近的一项现实含义。第二项只有在证据接近、且会改变结论或行动时才保留，并说明需要哪条现实信息才能区分。不能把一个父母爻同时展开成单位、合同、电话、房屋、车辆和长辈，也不能把同一动爻的所有物类逐项写成“都可能”。

象义必须落到具体句子：谁或哪个环节，发生什么作用，当前处于哪一阶段。只有“竞争激烈、压力较大、事情反复、后续有变化”而没有作用对象与结果差别的句子，不构成有效断象。

## 联象操作

每一条细节写成：`所问对象 → 依据爻/卦 → 关系 → 候选象义 → 现实核对/限制`。

| 连接方式 | 可操作方法 | 限制 |
|---|---|---|
| 卦与卦 | 上下卦、本变卦的物象相连；山水可候选为山环水抱，震离可候选为雷电 | 必须与所问领域相符 |
| 卦与爻 | 将六亲、五行所在的卦作为背景；同一父母爻在文书问题与住宅问题中分别取文书、房屋 | 不能把全部象义同时当成事实 |
| 爻与爻 | 以生克、冲合、刑害、进退、伏现为事件关系 | 先验证关系与力量确实成立 |
| 爻与六神 | 六亲定类别、六神补性质，例如财与青龙可候选为喜庆、酒食经营 | 青龙不自动等于盈利 |
| 爻与行运 | 依次引入相关年、月、日、时地支，追踪触发、解救和后续影响 | 不必把所有时段全部穷举 |
| 爻与爻辞 | 用当前卦及实际爻位的辞义，补充进退、积累、离散等情境 | 当前数据未提供完整卦爻辞；未核实爻辞不可引用 |

联想的四种方式：

- 接近：按时间、空间或事物关联取象，例如水爻对应水域，父母爻对应所问的父母、文书或房屋。
- 相似：按形状、功能、性质相似取象，例如桃花对应美观，父母爻在交通问题中候选为车辆。
- 对比：按本变之间的反差取象，例如艮到坤可候选为高处到平地，坎到离可候选为暗到明。
- 因果：沿病点、致病点、药、助药的关系追踪，不停留在单一符号。

限制：联想是候选解释，不是获取现实隐私或证实事件的证据。现实资料与象义冲突时，不得以象义推翻已知事实；也不得把未给出的背景编成“已发生”。完成候选筛选后，不在输出中复述被淘汰的象义。

## 从一个点展开关系

选中一个关键爻或行运地支后，检查七类关系：生、克、冲、合、刑、害、十二长生状态。不是强制每次都产生七个结论。

1. 记录它直接作用于哪些爻。
2. 检查被作用爻是否又是别爻的原神、忌神或通关者。
3. 标出由直接变化引发的间接变化，例如原神被冲破，受生者失去来源。
4. 检查需要怎样的条件恢复关系，例如冲破待合或填实、休囚及绝待生旺、静空待值冲。
5. 只输出与问题有关、关系足够明确的支路。

若输入出现“冲官已”等与官亥对象冲突的字样，不把它当作关系口诀；地支关系应查基础表。

## 卦名作为整体背景

条件：分析某爻。→ 判断：先确认它属于哪个本卦、变卦或上下卦环境，再解释局部变化。卦名表整体状态，爻表其中的人事与局部变化。→ 限制：卦名的背景作用不可替代已经计算的五行关系。

条件：同一卦名对应不同六亲或问题。→ 判断：使用与该问题相关的一种解释。→ 限制：卦名不是只有一种固定事件，也不能仅凭谐音或字义下结论。

可用的示例映射：

| 卦名/变化 | 候选表达 | 使用条件与限制 |
|---|---|---|
| 小畜 → 大畜 | 积累从少到多、停留从短到长 | 必须指定积累的是财、工作量或其他对象；不能自动推断发大财或大病 |
| 履 | 行动、迁移的候选背景 | 需配合动爻、父母爻或实际迁移问题 |
| 鼎 | 容器、烹调、饮食、供养 | 结合财、口象、经营背景可候选餐饮；不据此猜真实职业 |
| 旅 | 在外、旅行、暂居 | 动爻、马星或实际出行资料支持时使用 |
| 蛊 → 蒙 | 失序、疑难、遇险而止的候选过程 | 不把它当作事故已发生的证明 |
| 巽 → 小畜 | 犹豫、暂留、退守的候选情境 | 仅作卦例启发；不是凡得此卦都必须回原行业 |
| 恒三爻动 → 解 | 原状态难持续，可能发生改变或解除 | 仍需相关爻及行运支持，不能凭此断婚姻必离 |
| 遁 | 退避、暂离、收敛 | 与实际阻力、损益和体用关系共同分析 |
| 离 | 明、文书、电器等；在相关语境可联想到分离 | “离”字不能单独推出离职或离婚 |

本、变、互、错、综可以提供不同背景；只有排法与卦名已核实时才引用，不能为迎合解释随意挑一个变体。

## 卦象与大爻

“大爻”指把一个三爻卦整体当作五行对象，“小爻”指卦中的具体六爻。

1. 确认母卦/卦宫五行，六亲归属依同一参照计算。
2. 将上、下卦的五行分别与具体体用爻比较生克、耗泄。
3. 若把上下卦赋予六亲，明确其参照也是母卦五行，不能混用多个“我”。
4. 将卦的环境影响与具体爻的局部强弱并列，说明它们是支持还是冲突。

示例：乾宫金为参照，乾金可视为兄弟，艮土可视为父母，离火可视为官鬼；天山遁五爻动后，上乾变离，可用“上卦兄弟转官鬼、下卦父母”辅助观察环境变化。不得由“官鬼”直接判定某位上司恶意或某人是小人。

## 爻象与位置

- 阴阳、五行、六亲、地支、六神、爻位、爻辞、数均可构成爻象；天干、纳音只在输入与规则齐备时使用。
- 父母爻：在相关问题中可为家、房屋、单位、文书；官鬼爻可为工作、职务；妻财可为资金；兄弟可为同行者。先依据问题定类。
- 五爻：出行问题中作为道路、途中环境观察点；交通或机械背景下可候选运转之物。
- 二爻：住宅问题中可作宅位，须与其他材料所规定的爻位体系一致。
- 内外卦：在工作调动等问题中可候选内地/外地、身边/外部；必须预先约定参照，不能事后改变。
- 多个财爻关联世：可提示多个资金来源或选择；不能直接宣称现实中有确定数量的机会。
- 爻辞出现“射鸟”等物象时，可以涉及鸟、照料、捕获等多种相关情境，不能把其中一个动作强认作事实。

## 数字使用限制

本段实例使用先天数：兑2、离3、震4、艮7、坤8；并出现本变卦数相加、动爻数加数、取十位与小数等做法。没有给出可统一决定运算、位数、单位和小数点位置的规则。

因此：只能在用户明确要求象数游戏且预先约定算法时展示运算，不用这些例子作为价格、人数、日期的自动精确测算公式。不同算法得出不同数字时如实列歧义，不以接近值认定命中。

## 现实校准

形成候选象后检查：时间季节与实际进度、地点和环境、人员关系与能力、事物的现实状态。只有相关且有证据的背景才参与解释。涉及疾病、死亡、犯罪、性关系等，卦象不构成事实证据或专业判断依据；需要用户给出的事实才能谈对应象义，不推断未披露隐私。
