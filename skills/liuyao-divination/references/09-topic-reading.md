# 分项占断

## 共用步骤

先定用神人与事用；看用与双原、全卦失衡和本变趋势；再用专题物类与时序细化。下列为取象与条件入口，不是一见某爻便确定发生某件事的断语表。婚恋、事业等由分散规则与卦例提取，未形成完整分类公式的地方不得补成固定断法。

先把所问事项拆成现实中必经的阶段，再判断卦局最远支持到哪一层；未出现中间链时，不由“用神存在”直接跳到最终成事。输出只解释用户所问阶段及其前一个关键条件，其他专题物类留在内部复核。

## 婚恋与合作

- 人物先按明确的关系设定；此体系自占代占可统一以世代表用神人。世应看双方，财官在具体关系中辅助取用，不能在同一链中混换人物。
- 生合可表示亲近、协作或牵连；冲可表示分离、变化，也可能冲开阻隔。先看它们对双方与所问结果的实际作用。
- 六合不必然和合。否虽六合，仍要看不通与合处受冲；六合化六冲可表示关系变化，须结合期限、动变与药能否维持。
- 本卦关系 → 互象的障碍或过程 → 变卦趋势，须保持所选顺序一致。旅、离等出行象可辅助解释异地或往返，但需场景证据。
- 空爻、破爻待填合，迎运到位可能由若即若离转向接触；是否达成关系仍查本变体用。
- 财多、青龙或桃花只能提示多种关系取象，不能计算恋人数量或认定不忠。未提供双方意愿时不可把“合”写成对方真实爱意。
- 世应之间的两间爻可在媒介、介绍人、程序或中间阻力已经与所问相符时取象；间爻发动再查它实际生克合冲谁。此条吸收《海底眼·间爻》，但不以“间动”单独断媒人欺骗或关系必败。

## 工作、事业、考试与文书

- 官鬼可取工作、职位、管理与事务阻力；父母可取单位、店面、合同、文书、证件、学习载体；财取收入或资金，子孙取产出、客源或解忧。
- 官对世有克：在工作语境中可能是事务约束，不自动等于失业。须看世是否承受、双原是否连续、官是保护财还是泄财生父。
- 父休破且原神受绊：先判断单位、文书或经营载体受阻；不能单爻断单位已经倒闭。
- 店铺经营按“场所/资格成立 → 客源/业务形成 → 收入 → 留存”顺序看，开店时间与得财时间可不同。
- 若原神被合，候选药为冲开合的支；若冲开同时伤世或财，则分别说明，不以“冲开即成”结论收尾。
- 考试、审批等仍须选定所问事用和期限；本模块未提供可独立算分数、录取名次的公式。
- 求职、任职、考试与审批要把官与父分开：官主职位、名次、约束或审核者，父主文书、证照、单位载体与答卷。二者都有气且作用能到世，才可说环节相互支持；父受财克或官受子制时，要指出具体受阻环节。此为《火珠林》《海底眼》“官得父辅、官文并看”的条件化吸收。

### 求职阶段判定

求职按现实流程分层，断到证据能够连续到达的最远一步：

1. **岗位存在：** 官鬼明现、变现或依飞伏规则具备显出条件。只有这一层时，只能说有岗位或岗位线索。
2. **简历送达与流程启动：** 父母爻代表简历、招聘系统、单位载体或通知，须具备存在与受作用资格；父动也要查它是传递还是受阻。
3. **联系与面试：** 官、父或招聘方节点需通过有权作用或时间触发到达世爻。只见官旺而与世、父无连续路径，不能直接断面试。
4. **录用意向与书面条件：** 职位链已经到世，并有招聘方的后续动作；书面 Offer 再查父母，薪资预算和条件另查财爻。口头意向、谈薪和书面 Offer 分开表述。
5. **入职与稳定：** 世爻能够承受职位，变卦中职位及来源仍有连续性，手续、条件与到岗节点没有被关键病点截断。

每个应期必须标注对应层级。一个官日或出空日只能触发其实际支持的阶段，不能同时写成HR联系、正式面试、Offer和入职。若不同渠道在起卦前没有分别立极，不按内推、招聘平台或具体公司强行分配爻位。

## 出行与交通

- 父母取车辆、船只、票证；世取所测人；马星和动爻看移动；结合卦象判停留、往返、始行。
- 由出发点经道路到目的地，逐个关键节点检查是否有生扶、阻隔、冲克及救应。动不一定成行，合可能绊住，反吟可表示来回、返程或反复维修。
- 世与父同时受损时，术数上偏向出行阻碍；现实是否能出发须根据天气、交通、证件和设备情况判断，不以卦象替代。
- 父动只证明行李、车辆、票证、消息或行程条件发生变化；它可以促成启程，也可以形成阻滞。结合《海底眼·出行》与《增删卜易·出行章》时，必须再看父对世与目的地的实际作用，不能套“父动必返”。

## 航运专用物类

| 符号 | 航运取象 |
|---|---|
| 父母爻、木、巽 | 船、船体；父母也可为船员或操船人 |
| 世 | 船主、所测船员、出海人，事先固定 |
| 亥子、坎、玄武 | 江河海、水路、水域 |
| 初爻 | 船底；初二也取起航点 |
| 五爻 | 航线、途中必经位置 |
| 六爻 | 终点、港口 |
| 土 | 陆地、码头、岸，也可为浅滩、暗礁、阻隔 |
| 合、冲、巽进退、反吟 | 绊住、起动、前后进退、返航等候选 |

先查船与人的状态，再查初二→五→六的航行路径。水过旺而克父/世，取水势与行船条件不协调；无水或土过旺，取水浅、搁浅或阻隔；金对木有克、又能生水，要同时检查船体与水势。不能不看具体父爻五行便认定“水一定克船”。

白虎、三刑和兄鬼若实际参与刑冲克害父世，可加强险阻取象，不能据此断船沉、人亡。父爻原神空而不能生，不能只因父临太岁便断可行；原神何时有效须另查应期。

例：五爻水伏土下，冲开土看似疏通水路；若伏水出后反冲克父，所选药仍存在损船的另一面，不能只解释成航路畅通。

## 失物、车辆失窃

1. 先定失物的事用：钱财取财，车辆证件等可取父，不能只看官鬼。
2. 坎、玄武、官鬼、灾劫等可作隐匿或失物线索；艮、勾陈、子孙、将星等可作约束、寻找或捕盗线索。是否使用神煞先查可靠表。
3. 飞神受冲发动，伏神暴露后再受其他爻克，按“飞动 → 伏出 → 受损”追踪，而非把飞伏关系简化成一条凶诀。
4. 找回条件看事用是否恢复、保护链能否制约损物链、世应有无接应；不能以单一“捕盗星出现”保证追回。
5. 内外卦和支位可给搜索方向候选，须结合实际丢失地点。不能凭象指认熟人作案或要求追捕某人。
6. 财物爻安静、有气且在内卦，可提高“仍在近处或室内”的搜索优先级；动、空或落外卦可提高“已被移动或在外部”的候选级别。此条取自《海底眼·失物》的位置启发，只用于排查路线，不单独决定能否找回。

## 健康相关占问

“病点”通常是卦局失衡点，不等于人体疾病。仅在用户明确问健康时才使用身体部位取象，且不能由卦判病名、怀孕、死亡或治疗方案。实际症状应依就医检查；所谓调神、补某五行只表示术数中的关系变化。

健康题可把官鬼作为病因、压力或症状线索，把子孙作为医药、医者或解除因素，再检查两者是否真的作用到人用神。《海底眼》《卜筮全书》的这一对应只能帮助拆链；子孙无力、受制或反伤世时不能因“子孙为药”强断有效，官鬼旺也不能推出病名、轻重或生死。
