# 求财与行情取象

目录：取用与双原；财世关系；财源状态；兄父官作用；六亲转化；行情分段；冲突与数值限制。

## 取用与双原

求财以财为事用，世为人；行情以财为价格与市场状态的象征。行情向好与本人得财分别判断，不能相互代替。财的第一原神为子孙，第二原神为兄弟；兄是否经子生财，是转凶为用的主要条件。

分析顺序：财本身 → 子孙能否生财 → 兄弟能否经子通关 → 关键节点的双原 → 全局病药 → 时间触发。不能把兄一律判劫财、官一律判坏事。

## 财与世

| 条件 | 此法取断 | 复核 |
|---|---|---|
| 世旺能任财，财生合世 | 易得、有承受条件 | 财本身有气，作用能到世 |
| 世静财来生 | 较易取得 | 有无合绊、截断 |
| 财克世 | 可取财来寻我 | 不覆盖世弱不能承财或其他事项受损 |
| 世克财 | 通常取主动求财较难 | 克得适度而能控制财时亦可得财，不能两句冲突随意选 |
| 财不生合克世 | 财与本人联系不足 | 需主动获取或另有桥梁 |
| 世财应子 | 对方有助财源之象 | 应子实际有用 |
| 世财应兄/父 | 争利或财源受扰之象 | 兄是否通关、父是否实际损子 |
| 世应皆空 | 双方条件未实，难落实 | 出空后另论 |
| 兄持世而官克兄 | 官虽护财却可能压制本人 | 与官制非世之兄分开 |

## 财与财源的状态

| 状态 | 取断与转机 |
|---|---|
| 财旺、财弱 | 分别取当前利益较足、较薄；须查真假强弱 |
| 财弱变旺、旺变弱 | 分别取后续改善、后续减弱 |
| 本有财变无财、本无财变有财 | 可取先得后失、先无后有；伏财与出伏也须查 |
| 财空 | 难落实，出空再查；不得直接说永久无财 |
| 财被合绊 | 暂难到手，冲开后查可否取得 |
| 财入墓 | 通常受阻；财多太旺时入库也可表示收藏归己 |
| 财多重叠、日月与动爻多重生扶 | 检查是否过旺，候选收藏期在库时，不把数量多直接当收益高 |
| 财休囚空破死绝、受刑克 | 当前求财不利；以生旺、合填等检查转机 |
| 财绝逢生 | 失而有恢复、先难后易的候选，先核有效生源 |
| 财遇三刑 | 受损取象，强弱和救应决定程度 |
| 财伏子下 | 得生的条件存在时可望取得 |
| 财伏官下 | 可能泄财、受阻；子能克官生财时查转机 |
| 财伏父下 | 先有消耗、取得不全之象；不固定为损失一半 |
| 财伏兄下 | 争利与损耗；旺相、持世及通关条件另论 |
| 子旺有气发动生合财 | 财源较足、有接续 |
| 子空、入墓、破绝或被父制 | 来源不足或受阻；子绝逢生查能否恢复 |
| 财旺子弱 | 目前有利，后续来源不足 |
| 财弱子旺 | 当前不足，后续有支持条件 |
| 财旺子空绝 | 可能只一度有财，难以持续 |
| 财破子旺 | 虽受损而有支撑，不能只看破便断无救 |
| 子空财破、子财皆空 | 落实与接续均弱 |
| 有子无财 | 有来源条件，待财出现或值期；不能把来源直接当实际收入 |
| 财子皆无 | 常规求财不利；行情篇另有极弱反转分支，见末节 |

## 兄、父、官的条件作用

**兄弟：** 旺动而无子通关，取争利、分财；休囚空破、墓绝或受制时克财能力减。兄动财空表示当下未直接受劫，不等于财已到手。兄动子也动、子无伤且财不空破，形成兄→子→财可取财源有根。兄绝逢生而无子承接，可重新加大克财；若子动承接，则可能转为生财。

官能合克兄且不压制世，可取护财、小得；官受冲导致失去控制，兄可能再伤财。兄克财有明确时限时，出该日或该阶段后须重算，而非永久定凶。兄过旺也有“过极反弱”的分支，不能只见旺就认定反转。

**父母：** 父旺动克子，表示财源受抑；父兄同动无通关，兼伤财源与财。父得官生，克子可能加重。父空待填，填后如能克子，反不利；父破绝得生、父化进亦须查此路径。父退、墓、受制或刑导致不能克子时可缓解。父旺财弱取付出多而收益少之象，不从父弱财旺计算劳动量。

**官鬼：** 官可以制兄护财，也会泄财、生父而间接克子。兄静而官动，通常要查泄财与阻碍；兄旺却无官制且无子通关，则财缺保护。官空、入墓是否不利取决于它原来是否承担护财作用，不能无条件“鬼空必跌”。

兄、父被三刑而失去伤财/伤子能力，可出现对财有利的分支；不是任何三刑都伤财，也不是刑到兄父必然利财。需确认实际受损者和作用链。

## 六亲转化

以下为某一阶段的术数趋向。变爻的作用、强弱、空破与后续时间决定转化是否兑现；“涨跌”是取象语言，不是交易指令。官鬼统一写官。

| 动爻→变爻 | 条件性取断 |
|---|---|
| 财→子 | 得源、接续，行情偏升 |
| 财→官 | 常取泄财、先好后损；若官有效制兄，则有护财反向作用 |
| 财→财 | 化进偏升、化退偏降；临日得旺或被合可暂不退，真退时另论 |
| 财→兄 | 争利伤本，先升后跌；子旺通关可缓，子弱父旺则不利加重 |
| 财→父 | 先易后难、后续财源受抑，可能仅一度之财 |
| 子→财 | 来源转收入，偏升；细段仍可能升后回落，不固定回落幅度 |
| 子→官 | 来源转为泄财或阻力，偏不利 |
| 子→子 | 进则来源增强，退则后劲减；不能据此固定“两处得财”金额 |
| 子→兄 | 回头生且能通关可偏升；兄旺子弱则争利，不一律吉 |
| 子→父 | 来源受回头克，后续接续不利；父官旺期须重点查 |
| 兄→财 | 先散后聚或跌中恢复；兄仍能克所化财时利益易被分夺，兄破则克力减 |
| 兄→父 | 回头生强化克财，父兄相助，偏不利 |
| 兄→兄 | 进则争利强化，退可缓解；空退有暂不退分支，出空再核 |
| 兄→官 | 官可制兄却又泄财生父，必须净评；总局可仍弱而局部回升 |
| 兄→子 | 能形成生子生财且财不空破时，先损后得或偏升 |
| 父→财 | 回头克制父，可减对子之伤，先难后获或跌中恢复 |
| 父→兄 | 兼抑来源与争财，偏不利 |
| 父→官 | 回头生强化父克子，偏不利 |
| 父→父 | 进则克子增强，退则减弱；取劳费反复，不自动折算收益 |
| 父→子 | 父仍能克所化子时不利；后续子有力生财、制官断父源时才有恢复 |
| 官→财 | 可取先阻后得；仍核财与世及是否回生官 |
| 官→父 | 官生父克子，偏不利 |
| 官→子 | 可取解除阻碍、财源出现；核实际生财能力 |
| 官→官 | 进则阻力或泄耗增强，退可减轻；官护财时不能照搬 |
| 官→兄 | 制兄与劫财并存，取分歧、反复，常偏不利；查官是否还能有效约束 |

## 行情分段法

先明确标的、问题是行情还是个人获利、起卦时点和所测区间。选月、周、日等阶段，区间细化时可以另起分段卦，但每张卦须记录范围，不能无限复占择取合意结果。

固定局势分平衡、上行、下行、起伏四类；看财及双原的真正强弱、生源、极端状态、送迎趋势。至少分别看开始、中段、后段。若使用更细阶段，可记录低迷、初升、回调、主升、末升、初跌、主跌、反弹、末跌，不能未证条件就强套完整周期。

应期按 [07-timing.md](07-timing.md) 逐支核算，可定位相对较强与较弱的候选时间窗。十分钟段是固定时辰内分段，不随开盘时间重新从子段排起。不得把旧例的交易时辰当成所有现行交易所的开市时间。

若用户明确要求梅花合参，分栏保留此行情口径：体克用或比和取上行；主互吉而变凶取先升后降，反之相反；离取升、坎取降、震巽取较大上行、乾兑取变化较小、艮坤取持平。此为专用象法，不能与六爻财世口径无声合并或覆盖财与双原的实际条件。

## 冲突与数值限制

- “财子皆无不利”与“财子皆无已到低点”属于常规与极端反转两个分支。没有过极判据与恢复条件时，只能判弱并待转机，不能保证见底。
- 财或子过旺有反转趋弱分支；兄或父过旺有失去压制后转强分支。材料未给可计算的“过极”阈值，不能以爻数、临日月便自动宣布极值。
- 同一“财绝逢生”有约10%与数倍等不同幅度说法，不能当定量公式使用。财伏父下“一半”、子财合局“万倍”等也不作计算值。
- 点数诀存在干支字形歧义；全卦数、互卦半数与实际价格单位缺少统一换算，不能生成精确点位或百分比。
- 市场指数、库存、政策等现实数据不从六亲取象中生成。需要现实金融判断时另据实际资料，不将卦中官父直接写成真实政策消息。
