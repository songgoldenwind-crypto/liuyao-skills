# 体用、强弱与双原

## 1. 先定两个比较中心

- 成卦后，先指定体与用：体是当前问题的主体，用是对应的人或事。其余卦爻先作为条件、影响来源或阶段，不与核心混在一起。
- 同一卦可以有多组体用，但每次比较只处理一组，并标明所问层次。不能把本卦的一组强弱，直接当作变卦另一组的强弱。
- 可按分析目的设立：世爻为体、其他相关爻为用；本卦为体、变卦为用；本变卦为体、互错综卦为用；本变卦为体、行运为用；年为体、月日时为用；月为体、日时为用。这里的“静为体、动为用”是相对关系，不表示静爻永远为体。
- 体用确定后，把全局作用归成两类：增益此核心者、损害此核心者。“五行归二行”指归成两组力量、抓两个关键矛盾点，不是把五行删成固定的两种元素。
- 围绕体用完成主判断后，可在原神、损神、调神及其喜忌处再立小太极点，重复同样的两方比较。各次立点必须写清主体，防止六亲与喜忌随意换位。

## 2. 强弱先于生克结论

条件：需要判断某爻能否生克冲合另一爻。

判断：先评估双方实际力量，再判断作用是否成立及程度。不能看到相生就判吉、看到相克就判凶，也不能仅凭六神名称决定吉凶。

操作顺序：

1. 定出全局五行最强点、最弱点。
2. 分别评估体爻、用爻、本体与来源。
3. 看增益、损害两组的力量、数量、源头、当令状态和行动趋势。
4. 看组合后实际是增力还是减力，再落定相对强弱。
5. 看这种强弱对所问之事有利还是有害；力量强与结果吉是两项不同判断。

限制：本法没有给出可量化的权重或“太旺、太弱”的分数阈值。使用“偏强、偏弱、极强、极弱、暂难分”等定性等级，逐项列证据，不虚构数值评分和概率。

## 3. 时间来源

| 条件 | 初步判断 | 必须再检查 |
|---|---|---|
| 爻临日月 | 旺 | 是否同时受有效克泄、冲破等影响 |
| 临日月且再得生助 | 极旺候选 | 是否过旺成病；有无顺势条件 |
| 得日月生 | 相、有气 | 原神能否真正生入；本爻是否受生 |
| 不临日月 | 暂作休囚 | 不能忽略同类、双原、动变和空间补助 |
| 受日月克 | 暂作死、受压状态 | 是否有救应、通关、冲合改变；“死”不是人的死亡判断 |

- 一般主看月日与当时行运，兼看年时。测年事重年，测月事重月，测日事重日，测时事重时。
- 日月并非最终静态判决。需同时列出过去、现在、将来的力量变化，尤其检查送运、迎运；即将进入的月份或时段是潜在力量。
- 新的行运到位后，重新计算原神、忌神及组合关系。不能把起卦时的旺弱永久沿用。
- 六神也随四时、行运出现强弱差别；六神的象与其力量应分别判断。
- 若日月提供相反条件，不能仅挑选支持结论的一项，须进入空间与组合分析。

## 4. 空间来源与组合

逐项检查本卦本爻、同类、双原、双夹、爻位、内外卦环境及特定卦爻组合：

- 同类、双原多且可发挥作用 → 有连续支持，较强；被制、隔断、合住、空破而不能作用 → 不按数量直接加力。
- 邻近条件有利、双夹有力 → 作为增益证据；不利条件多 → 作为减力证据。当前材料没有独立给出“双夹”的完整取法，不自行发明夹拱或相邻权重规则。
- 内外卦对同一冲克力量的生泄不同 → 可以出现内破外不破、内外得失不一的判断，不必强行归为全卦同一结果。
- 时间与空间结论不一致 → 以全部组合的最终增减为依据；不能只凭时令或只凭爻数判旺弱。
- 地支相邻不等于性质相同；同属一个大方位仍可能有不同的冲合关系，必须细分支位。

匿名简例：某局官酉得令又得土生，兄卯被酉冲，子巳休囚又化父回克。父爻虽初看弱，但得旺金生；子巳既受克，原神木又被破，所以综合最弱点可能转为子巳，不能按第一轮时令印象认定父爻最弱。

## 5. 双原法

### 定义与检查链

“双原”在这里明确指原神与原神之原，不是两个同名原神。

对每个关键爻建立：`本体 ← 原神 ← 原神之原`。

以官爻为核心时，检查财爻，再检查财之原神子孙爻。以其他爻为核心时，依五行相生关系类推，不固定只看这两种六亲。

依次记录：

1. 本体当前旺弱、空破墓绝、动静及是否能受生。
2. 第一原神的旺弱、可否到达本体、是否被合绊或克泄。
3. 第二原神的旺弱、是否能供给第一原神。
4. 两层来源随行运发生的改变，是否会续源、断源、转为损害。
5. 重新合看体用双方及病药双方的来源，最后检查全五行，不停在单爻。

### 条件判断

- 有源、源头连续且生路畅通 → 支持持续性较好。
- 源头受阻或原神有名无力 → 支持不足，不能按“有原神”就判有救。
- 本爻暂旺但无源 → 可能不能持久，需检查后续行运。
- 本爻弱但双原有力、即将得运 → 可以提出转强条件，不能提前当作已经转强。
- 第一原神被合而不能动 → 即使财或本体旺，也可能供给中断，事件停滞。
- 本体破而不受生，或生中有刑 → 原神发动来生不等于受益。分别列“有来生”与“生是否入体”。
- 双原被强势忌神控制 → 原神链可能反成病源，须追踪到致病点。

### 特定用法保留

某例财子动化官卯，日建酉冲变爻卯，推断时将酉视作到此，称财子“化子酉回头生”。这是本体系的行运临位取象，不是原始变爻真的改为酉；展示卦盘仍保留原变爻卯，另列“日建酉冲入变位”的解释。此规则仅有个例说明，不能推广为任意日冲都替换变爻。

同例把官卯判作内卦破、外卦不破：内坤土生酉金加重冲卯，外坎水泄酉并生卯；但子卯又有刑，因此外来生扶仍须检查刑与受生。此例后续自我修正了“有财来即进财”的判断：世破不受生，反可能财向外流。以修正后的作用链为准。

## 6. 阴阳平衡与变势

- 增益与损害相对均衡 → 可判当前中和；不是要求五行数量完全相等。
- 增益多 → 本体偏强；损害多 → 本体偏弱。再按所问事判断强弱是否适宜。
- 过强或过弱 → 检查失衡点和调神，转读 `04-adjustment.md`。
- 一方强到难以逆转、弱方无根无援 → 检查从强、从势；不能机械套用“弱必扶、强必克”。
- 强极转弱、弱极转强 → 作为变势检查项，需要行运、来源、组合改变的具体证据；“物极必反”不能独立推出任意反转日期。

## 7. 多组体用示例

婚姻局中可以分别看：

- 本卦世子申强、应官卯弱空 → 在此体用组内是世强应弱，检查子克官、男方退避等象。
- 变卦世兄丑被兄未旺冲并构成刑 → 在朋友关系这一组内是世弱对方强，检查冲突与沟通失和。

两组强弱不同并不自动矛盾，前提是分别说明主体、阶段与问题。不得由一次子强官弱直接贴上人格标签或断定某一性别天生不利婚姻。

## 8. 取象与文字限制

- 比卦上爻动，可结合“比之无首”保留虚亲、虚合的个例解释；不能仅凭“第六爻动”把所有卦结论一律反转。
- 材料多处以“已、末、戊”混写“巳、未、戌”。仅当地支序列、五行及冲合关系明确时规范字形；涉及具体日期、时刻或卦盘时不能凭猜测补定。
- “源有气”“受生”“不破”是不同层次，不能互相替代。每次输出保留使判断成立的条件。
