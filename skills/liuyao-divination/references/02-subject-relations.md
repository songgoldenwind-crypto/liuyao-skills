# 取用、立极与六亲映射

## 人用神与事用神

用神是本次所测的人、事、物或时空在卦中的代表。先明确对象和范围，再取对应卦爻；确定后以它为中心审查其余卦爻的作用。

1. 取人用神：确定谁是分析主体。
2. 取事用神：确定本次要考察的事项，以及组成该事的必要环节。
3. 写出“现实对象→代表卦爻→所问关系”，再判断旺弱、生克与病药。

例：测自己的生意，可先用世爻代表本人，财爻代表收入或利润，子孙爻代表财源、本钱或客户，兄弟爻代表竞争、费用。不能只看到财爻就略去财源和成本。

### 两种取用模式必须分明

| 条件 | 判断 | 限制 |
|---|---|---|
| 采用传统亲属取用 | 自占以世为本人；父母、子女、配偶、平辈等按相应六亲取用，彼方可参考应爻 | 需弄清关系；用神多现的完整择取优先级在此未规定，不能补造 |
| 采用本体系快捷取用 | 起卦前约定，无论自占代占，世爻均代表真正被测的人 | 这是本体系的可选独特规则，不是传统六爻统一规定 |
| 代占关系不明但被测目标明确 | 可预先取世为该目标，不必用亲属辈分推定人用神 | “不知姓名或辈分”不等于可以不知道究竟在测谁；不能虚构身份 |
| 同时分析多个对象 | 分别列出每个对象的代表以及彼此关系 | 不在同一步骤中让世爻同时代表提问者与被代占者，却不作区分 |

快捷取世解决的是人用神定位，不能代替事用神选择，也不能保证任何判断必然准确。已经按一种取用解释的盘，不因结论不合意暗中换另一种。

## 世应与六亲基本物类

下表是候选象义。先按所问选择相干项，再用卦爻强弱、作用与时间验证。六亲名称本身不能直接证明现实人物的性格、职业、疾病或行为。

| 标志 | 人物与关系 | 事项与物类 |
|---|---|---|
| 世爻 | 我、我方；快捷取用时为实际被测者 | 本人状态、精力、情绪、处境、健康与整体事态 |
| 应爻 | 对方、彼方、客户、宾客、伙伴、对手、所测他人 | 与问题相对应的事项；位置、朝向等须符合所问 |
| 父母 | 父母祖辈、长辈、师长、照料者 | 家宅、土地、建筑、单位、车辆船舶等交通工具、衣被及庇护物；书信消息、电话、文书证件、合同手续、考试学业、知识技术；辛劳、操心；身体体质、头脑、思考与能力的候选象；雨雪冰雹、浓云雾 |
| 官鬼 | 丈夫、婚恋男方、主管领导、官方人员、敌手 | 工作职业、任职离职、晋升调动、事业、功名、政府法律、诉讼、战争、约束管理；忧疑、惊恐、事故、疾病、盗窃等候选象；雷电、阴云；厅堂 |
| 妻财 | 妻子、婚恋女方、家庭主妇、产妇、商业财务人员 | 钱财收入、利润薪酬、资金价格、货物财产、求财交易；食物粮食、厨房；理由、数理；晴旱 |
| 子孙 | 子女晚辈、胎儿、儿童、学生门徒、下属、医生等 | 生育、娱乐玩具、动物畜产、医药、解忧避灾、和解；精神爱好、自由职业；财源、本钱、存款、投资与回收；日月星光、晴、顺风 |
| 兄弟 | 兄弟姐妹、平辈、朋友同学、同行同伴、竞争者 | 人际交际、义气、争夺竞争、费用耗财、分财、价格折损；手脚肩臂等部位候选象；门户墙壁、卫生间；风、云 |

重叠象义按问题和作用划分：父母可以指学业文书，官鬼可以指学习所求的功名职位；应爻可指对方客户，子孙可在求财链中指财源客户。不能因为同一物类可落多个标志，就把它们认定为同一个现实对象。

## 六亲作用的条件判断

| 条件 | 可推演的事项方向 | 例外与限制 |
|---|---|---|
| 父母爻实际克制子孙，且子孙为所需之用 | 财源、本钱、子女、动物或医药环节受阻；求财可能劳而少得 | 父母并非一概凶；文书、房屋、学业等事项中可为所求。不能据此断定无药可治或绝嗣 |
| 官鬼实际克世，且不能转化为所需作用 | 可列忧患、约束、病事或事故为候选方向 | 官鬼亦代表工作、职位、丈夫；先辨所问及喜忌，不见官即断灾 |
| 官鬼实际克兄弟，且兄弟为所需之用 | 同伴、手足或相应事务受压 | 若兄弟本为劫财之忌，其受制可转有利 |
| 妻财实际克父母，且父母为所需之用 | 文书学业、消息手续、长辈、住宅车辆等环节受损或不顺 | 不可由财爻出现直接推出车祸、父母死亡；须有对应事项和完整作用证据 |
| 子孙能够生财且为所喜 | 财源、本金经营、客户、投资回收或资金供给可为有利环节 | 子孙强弱兼可观察求财意愿与用财能力；不能只凭一爻反推确切存款或金额 |
| 子孙克官且官为工作、功名或婚恋男方的所需之用 | 可考虑停职、转换工作、求名受阻或关系受损 | 若官代表忧患疾病，子孙制官可表现为解忧、缓解、医治的候选象 |
| 兄弟发动并实际劫财 | 费用、竞争、分财、折价、收入受损；婚恋中可观察争夺或矛盾 | 是否破财、何时发生、大小程度仍由全局决定；不能见兄即断贪污、抢劫或不忠 |
| 诉讼以财为理由，我方财持世又受克 | 可列理由受挫、争讼不利方向 | 不是法律事实判断，也不跳过其他作用因素 |

子孙的财务象需细分：既可表示已有本钱、在家或库中的财，也可表示拟投入的财、财源和回收中的财。应按“持有→投入→产生收入→回收”的具体问题定角色，不能把同一符号同时算作全部现金流。

涉及身体部位、疾病、寿夭的物类只保留为术数象义，不用作医疗诊断、疗效判断或治疗指令。生育条目中“强则生产不用忧，不育”存在表述不清，不能据此建立确定的生育能力规则。

## 其他取用入口

在问题明确且资料足够时，可按天干、地支、五行、六神、神煞、爻位或卦象等取用，并注明入口：

- 年干取长辈，月干取平辈，日干取自身，时干取晚辈。
- 寅可取猫；测火灾示例取午火。动物与五行取象不能代替实际事件证据。
- 玄武可取盗，马星可取车，将星可取官；前提是相应六神神煞已可靠排定。
- 二爻可取家宅，五爻可取道路；仍须与本次问题相符。

这些入口是按事项使用的候选规则，不构成完整对照表。对未提供的神煞算法、卦数映射或含混字词不自行补齐。

## 立极与关系追踪

立极：把某个已经定位的人、事或卦爻当作当前分析中心。它的用途是围绕一个明确对象展开相关信息，不是凭空增加事实。

1. 从主问题的人用神、事用神入手。先看整体卦势与时间，再找全局的失衡点、受损点或关键作用。
2. 选与问题直接相关的卦、爻、六亲、五行或六神作为太极点，注明“当前中心是何人何事”。
3. 围绕此点查看自身旺弱、来源与生扶、所受克泄、动变、与其他对象的关系。需要深入子问题时，再选一个已明确的相关点。
4. 每次转换都保留前后关系链，例如“本人→生意收入→财源→客户”，而不是任意切换主题。
5. 得到反馈时，把已确认信息与尚未确认推演分开，再决定是否进一步追踪。

限制：此处说明可在任何相关点立极，但没有列出一套完整的“切换太极后重排全盘六亲”算法。不能把立极自动解释为重排纳甲、改变原六亲或改变世应；需要新的相对六亲映射时，必须明确其计算依据，与原盘标注分栏。

### 双卦同步信息

条件：同一问题已有两个独立卦盘。

判断：分别分析后，比较共同卦象、同一爻位的动变、相同五行的受损或生扶、相同六亲的显现。同步处可作为继续立极的候选突破点。

限制：重复符号提升的是体系内关注度，不自动构成必然事实或“绝对信息”。不得由几个重叠象义直接确认职业、伤亡、婚外关系等具体事实。

## 用神与调神不要混淆

用神回答“测谁、测什么”；调神回答“什么作用能改善当前失衡”。

条件：已综合本变两卦、四时、旺弱与生克，找出关键失衡。

判断：考虑通关、制衡、调候等方向，选择一两个对全局有利的爻或地支五行作为调神候选；再检查是否有力、受阻、空静，以及何种时间条件可使其起作用。

例：需要生扶的土弱，金又泄土；欲扶金须土，土本身无力，则继续追踪能生土的火是否可用。若火空静，必须进一步检验何时填实、值冲等条件，不把“找到了火”当作已经得救。

限制：本变十二爻是整体观察范围，不表示十二爻在任何情况下都能无条件互相作用；具体作用资格、喜忌及应期条件须另行验证。调神不能脱离人用神、事用神及所问利害，亦不能因某六亲惯常称吉便直接指定。
