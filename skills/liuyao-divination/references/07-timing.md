# 行运与应期

## 时间层级

先确定占问期限。年运看年月，月运看月日，日事看日时；只有输入和问题需要时才推十分钟流分。不能将日事中的小波动升级成人生灾变，也不能把月运的变卦无限外推。

“本变静卦”指起卦时固定记录的本卦与变卦整体，包含发动与变化的结构，不等于六爻均不动。“本变动卦”指将流年、流月、流日、流时等时间因素代入后的动态状态，不等于另摇一卦，也没有提供一套可任意重排纳甲的运卦公式。

先看本变固定局势的事项征象，再看行运何时触发。行运出现了一个象，而本变盘与所问均无相应主因，不把它升级为主要事件。本变局势决定此法中的推断范围，不代表现实命运绝对不变。

## 应期条件表

下表用于生成候选时间，不能脱离病药直接套吉凶。

| 当前状态 | 候选触发 | 复核 |
|---|---|---|
| 爻动且旺相 | 值本支、逢合 | 合是成事还是合绊；动爻是药还是致病因素 |
| 化进、化退 | 本支或变支逢值、冲、合 | 进退是否当前有效，有无暂时被合住、得令不退等条件 |
| 忌神临值 | 忌神值日、值时等 | 是否真能伤体用，是否有制化或通关 |
| 忌神受冲克、入墓或临绝 | 制约它的时段 | 无力之忌与冲而被激活的忌区别；不能一见冲忌便吉 |
| 休囚或临绝 | 得生、临旺之时 | 生源能否实际到达、是否被合绊或截断 |
| 爻多、过旺 | 入库收藏、制约或泄耗的时段 | 过旺有无被调平；入墓是收藏还是堵住有用之源 |
| 入墓、被合绊 | 冲开墓、冲散合的时段 | 冲开后释放的是药还是病；勿把所有合都当合绊 |
| 静爻、空爻 | 逢值、逢冲 | 旺静受冲可能动，弱空受冲可能破，须重新定状态 |
| 冲破 | 合住、填实 | 日破月破、当前失效与后续可恢复须分时判断 |
| 长生条件 | 长生之时 | 使用的长生口径明确，生源实有，不补造未提供的表 |

简诀覆盖：动旺取值合；进退取值冲合；忌值查受害；忌受冲克墓绝查解制；休囚绝取生旺；太旺取库藏；墓合取冲开；静空取值冲；冲破取合填；长生取生时。

## 逐支推断

1. 记录主问题在本变局势中的征象，及致病点、病点、候选药。
2. 由条件表产生候选时间支，结合占问时限列出相关年、月、日、时。
3. 将每一候选支加入原局，重新检查：生克、冲合、空破、墓绝、进退、双原有无通路。
4. 同一时间既救一爻又伤另一爻，列明两面，按所问体用取舍，不能只取有利半边。
5. 对候选时间排序，写明事件类型与触发链；有条件无法核实则保留为候选窗。
6. 需要公历日期时使用可靠历法结果核对；只有“申日”不得自选某个公历日冒充唯一应期。

## 送运、现运、迎运

- 送运是已经过去的时间，现运是正在经历的时间，迎运是随后将至的时间。
- 看某年同时联看前后年；看某月同时联看前后月。至少查下一个迎运，事件尚不能形成时继续看期限内后几个行运。
- 迎运可改变用神是否出空、填破、生旺、受制，因而形成结果；尚未来临的条件必须写成未来条件，不能挪到当下。
- 同支重临只表示结构相似，不能把上一周期的事件原样复制到下一周期。
- 回看既往只作核验，已过时段不能列作接下来会发生的应期。

## 四种顺序

| 顺序 | 用法 | 限制 |
|---|---|---|
| 本变与行运 | 固定局势定问题，动态时间定触发 | 未有主因不靠流时凭空生成重大事件 |
| 送现迎 | 前因、当前状态、下一条件连看 | 时间单向推进，不能倒放 |
| 空间路径 | 从起点、必经部位到目的地，逐点查作用 | 原有空间法细则不全，只在实际路线和爻位关系明确时用 |
| 病药链 | 致病方作用于病点，药到后改变局势 | 多动爻不预设同时起效，依时令与实际作用链排序 |

本卦—互卦—变卦可辅助描述当前、过程、趋向；互卦有时也用于内因。采用何种含义须事先明确，不能同时把互卦当过去与未来来凑结论。

## 十分钟流分

此法把一个120分钟时辰分成12段，段支固定从子排到亥。这里的“子段”是时辰内分段，不是另一个子时。

| 从时辰起点起算 | 段支 |
|---|---|
| 0–10分钟 | 子 |
| 10–20分钟 | 丑 |
| 20–30分钟 | 寅 |
| 30–40分钟 | 卯 |
| 40–50分钟 | 辰 |
| 50–60分钟 | 巳 |
| 60–70分钟 | 午 |
| 70–80分钟 | 未 |
| 80–90分钟 | 申 |
| 90–100分钟 | 酉 |
| 100–110分钟 | 戌 |
| 110–120分钟 | 亥 |

以左闭右开区间计算。例：巳时09:00–11:00，09:45为辰段，10:00为午段，10:51为亥段，11:00已是午时子段；不存在“10点60分”。后半时辰的“0–10分钟”实际是从整个时辰起点起第60–70分钟，不能误排为子段。

`python3 scripts/time_segments.py 2026-09-06T10:51:00+08:00` 返回时辰、段支、起止时刻。此脚本采用输入偏移量对应的民用钟表时间，子时23:00起；不进行真太阳时修正，也不决定换日、日柱、旬空。分段清楚不意味着预测精度达到十分钟。

## 匿名条件例

财子破，兄丑空动且可合子：先看未时段能否冲起丑，继看申能否通关生水或成局，不能只因当下财破断整个期限无财。若丑虽起而通关不成，仍不能认定财已恢复。

土过强、水弱，本卦木世亦弱：申可泄土生水，水再生木；酉虽也属金却可能冲破卯世。候选应期不能合并成“逢金皆吉”。
