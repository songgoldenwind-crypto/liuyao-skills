# 六爻测算

围绕所问之事，按“核盘 → 立体用 → 查全局与双原 → 定致病点、病点、药 → 排事件与时间顺序 → 断象”推断。所有吉凶均是此术数体系内的判断，不把卦象推演写成已证实的事实。

## 输入与核盘

先利用已有信息，只追问影响当前判断的缺项：占问、所测对象、时间范围、起卦方式、原始数或六次爻值、起卦时间与时区、已有卦盘。只有起卦时间不等于已提供时间起卦算法；仅有本卦名不等于已知动爻。完整可靠的本变卦名可经爻画差异核出变化位置，但不能由此补造日期、旬空等字段。局部规则问题直接按给定条件分析，不强求无关的完整卦盘。

接收图片卦盘时逐爻核读，不确定的字或爻画先标疑。爻序自初爻向上；记录本卦、变卦、动爻、地支五行、六亲、世应、伏神、月建日辰与旬空。核实六亲采用的卦宫口径。缺纳甲、历法或装卦依据时不生成貌似完整的卦盘；可先分析确定部分。

起卦和核盘读 [01-casting-subject.md](references/01-casting-subject.md)。使用 `scripts/time_segments.py` 可将给定时区的钟表时间分成时辰与十分钟流分；它不排干支、纳甲或旬空。

## 断卦主线

1. **立体用。** 读 [02-subject-relations.md](references/02-subject-relations.md)，明确“谁是用神人、问什么事”。按本体系设定世爻为用神人，事用另取；代占、子问题与另立太极点须写清代表关系，不能中途无声换人。
2. **定真实强弱。** 读 [03-strength-balance.md](references/03-strength-balance.md)，看全卦五行、本变体用、第一原神及原神之原，必要时追源。区分表面得令与实际能生、能受生；不得只按旺衰标签或爻数投票。
3. **锁定病药。** 读 [04-adjustment.md](references/04-adjustment.md) 的选药与副作用部分，将造成失衡的作用方、受损点、能恢复流通的因素分别列出；候选药须同时检查对本变体用及其双原的利弊。同五行的不同地支不能互换。
4. **串联主因。** 读 [08-reading-flow.md](references/08-reading-flow.md)，先总览，后聚焦主要矛盾，按“触发 → 受作用 → 动变 → 后续”组织，避免把几个动爻写成同时发生。
5. **细化所问。** 按需读 [05-imagery.md](references/05-imagery.md) 和 [06-symbol-tables.md](references/06-symbol-tables.md)。先有生克与病药证据，再以卦象、六亲、六神、爻位限定含义；神煞只作辅助。多个现实含义并存时给最贴题的候选，不编人物经历。
6. **定时间。** 问何时、过程或流运时读 [07-timing.md](references/07-timing.md)，先在本变局势找到事项，再将相关时间地支逐一代入，联看送运、现运、迎运。只给数据支持的时间窗。

## 输出

直接回答所问，必要时使用下列结构，避免每次机械铺满：

- **判断：** 目前趋势或能否判断。
- **依据：** 关键体用、双原、致病点与药，写明实际生克链。
- **过程与应期：** 哪个条件先发生、哪些时间窗触发，哪些尚不能确定。
- **可做之事：** 用户问建议时给与问题相符的现实行动或注明性质的象征方案。

不输出寒暄、署名、宣传、文学铺陈、学习感言或事后“神验”故事。保留规则的条件、反例和必要的测算限制。缺字、算法不全、神煞异文和冲突规则不得靠想象消除。

卦象不作为医疗诊断、死亡断言、犯罪指认、他人隐私事实或证券交易指令的依据；遇此类占问，只表达术数取象及其不能确认的部分，现实处置依据事实。不得把“旺极必反”转换为真实市场必然见底或见顶的保证。
