# 六爻测算

围绕所问之事，按“核盘 → 立体用 → 查全局与双原 → 定致病点、病点、药 → 排事件与时间顺序 → 断象”推断。所有吉凶均是此术数体系内的判断，不把卦象推演写成已证实的事实。

项目内六爻古籍已经按取用、强弱、飞伏、动变、应期和专题占断等规则节点吸收到下列参考文件。所有占问仍走本体系这一条主线；古籍书名只作规则溯源与冲突辨识，不构成让用户选择的流派，也不以临时检索某本书代替完整断卦。

## 输入与核盘

先利用已有信息，只追问影响当前判断的缺项：占问、所测对象、时间范围、起卦方式、原始数或六次爻值、起卦时间与时区、已有卦盘。只有起卦时间不等于已提供时间起卦算法；仅有本卦名不等于已知动爻。完整可靠的本变卦名可经爻画差异核出变化位置，但不能由此补造日期、旬空等字段。局部规则问题直接按给定条件分析，不强求无关的完整卦盘。

接收图片卦盘时逐爻核读，不确定的字或爻画先标疑。爻序自初爻向上；记录本卦、变卦、动爻、地支五行、六亲、世应、伏神、月建日辰与旬空。核实六亲采用的卦宫口径。缺纳甲、历法或装卦依据时不生成貌似完整的卦盘；可先分析确定部分。

起卦和核盘读 [01-casting-subject.md](references/01-casting-subject.md)。使用 `scripts/time_segments.py` 可将给定时区的钟表时间分成时辰与十分钟流分；它不排干支、纳甲或旬空。

## 断卦主线

1. **立体用。** 读 [02-subject-relations.md](references/02-subject-relations.md)，明确“谁是用神人、问什么事”。按本体系设定世爻为用神人，事用另取；代占、子问题与另立太极点须写清代表关系，不能中途无声换人。
2. **定真实强弱。** 读 [03-strength-balance.md](references/03-strength-balance.md)，看全卦五行、本变体用、第一原神及原神之原，必要时追源。区分表面得令与实际能生、能受生；不得只按旺衰标签或爻数投票。
3. **锁定病药。** 读 [04-adjustment.md](references/04-adjustment.md) 的选药与副作用部分，将造成失衡的作用方、受损点、能恢复流通的因素分别列出；候选药须同时检查对本变体用及其双原的利弊。同五行的不同地支不能互换。
4. **串联主因。** 读 [08-reading-flow.md](references/08-reading-flow.md)，先总览全盘，再收束为一条足以回答所问的主因果链，按“触发 → 受作用 → 动变 → 后续”组织。其余信息只在会改变主结论时输出。
5. **细化所问。** 按需读 [05-imagery.md](references/05-imagery.md) 和 [06-symbol-tables.md](references/06-symbol-tables.md)。先有生克与病药证据，再以卦象、六亲、六神、爻位限定含义；神煞只作辅助。多个现实含义并存时先按用户已知背景和作用链筛选，通常只输出最贴题的一项。
6. **定时间。** 问何时、过程或流运时读 [07-timing.md](references/07-timing.md)，先在本变局势找到事项，再将相关时间地支逐一代入，联看送运、现运、迎运。只给数据支持的时间窗。

## 输出收束

完整查盘用于保证不漏掉反证，不等于把全盘信息全部写给用户。落笔前先完成四项收束：明确用户究竟问哪一个结果及期限；判定卦局最多支持到哪个事件阶段；选出一条主因果链；找出会推翻或限制主判断的最强反证。

直接回答所问，默认采用下列顺序：

- **判断：** 用一至三句给出一个主判断，明确当前处于什么阶段、能走到哪一步。不要先罗列卦盘或用“有好有坏、存在机会、可能反复”代替结论。
- **主因：** 只展开最能决定结果的一条作用链，通常列二至四个关键节点。第二条链只有在它能改变成败、阶段或时间时才写。
- **过程与应期：** 最多列三个有区别的时间窗，每个窗口标明对应的是消息、接触、推进、确定或完成中的哪一层。只有完整触发链支持时才落到具体日，否则使用旬、月或更宽的区间。
- **限制：** 只保留一个最关键的未决条件或相反信号，并说明它会把结论改变到哪一步。其他边界在不影响理解时不逐项堆叠。
- **可做之事：** 用户问建议，或现实动作会直接改变关键病点时再给；动作须对应盘中明确环节。

候选现实含义通常只输出最贴题的一项；只有两项证据接近且会导致不同结论时，才增加一个备选，并写清哪条现实信息可以区分。卦名、六神、爻位、神煞和古籍规则主要用于限定主链，不分别扩写成独立故事。

逐句检查具体性：若删除卦爻名称后，一句话仍可套用于大多数占问，例如“过程有压力”“后面可能反复”“条件会有调整”，就删去或改写为具体对象、作用、阶段和触发条件。结论不在多个段落换词重复。

用户明确要求全盘、教学式或逐爻分析时可以展开，但仍先给主判断和主链，再把扩展内容按主次排列。

不输出寒暄、署名、宣传、文学铺陈、学习感言或事后“神验”故事。保留会改变结论的条件、反例和测算限制。缺字、算法不全、神煞异文和冲突规则不得靠想象消除。

卦象不作为医疗诊断、死亡断言、犯罪指认、他人隐私事实或证券交易指令的依据；遇此类占问，只表达术数取象及其不能确认的部分，现实处置依据事实。不得把“旺极必反”转换为真实市场必然见底或见顶的保证。
