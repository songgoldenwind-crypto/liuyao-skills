# 专题条件式断语

先按 `04-reading-procedure.md` 核期限、阶段与主用；本文件补充各类事项的取用与条件关系。

## 工作、职位与职业

取用：世为本人，官为职位；应可为公司、领导或就职地；财为工资资金，兄为同事竞争，子为员工或剥职，父为单位、账目、文书或劳碌。每次先固定角色。

| 条件 | 取断 |
|---|---|
| 官休囚空动化子克、入日墓 | 旧职丧失或辞职候选；月上已衰、日墓可指过去残留 |
| 另有官用，其财源出伏能生 | 可看未来工作；不可让旧用受伤覆盖另一个可用岗位 |
| 官生父而自化回头克 | 为单位劳碌后自己辞职候选 |
| 官世化克、又受应克，但得日救 | 先受阻后可调动；结果可能延迟 |
| 员工子孙在应化退却旺 | 有暂不退、能带人过去的候选；和本人调动分开判 |
| 官空化子克、另子动克官、就职应又化克 | 升迁不利，可能降职或调低 |
| 官被子动克，子自身又化克化散，官得日救 | 剥职作用受制；可有先待岗后恢复，不等于从未失职 |
| 世受官克、兄冲 | 与领导同事发生压力或冲突，离职候选 |
| 官旺而遭子孙化进克 | 不能因官旺直接断获职；可取岗位反复受损，不固定次数 |
| 公司父月破、空被冲脱，兄化退 | 公司变动、解散及员工离去的组合候选 |
| 官出伏却被子动克 | 当期工作受阻；另有日生旺用时可分旧职与新职 |
| 应试图生财却生不到，父公司受损 | 资金条件阻碍公司运转；伏财旺、飞空可留未来改善条件 |
| 官得日生合但世自己化退 | 岗位未被全克尽，本人仍可能主动离职 |
| 静官为原态、动官空化子 | 看发展岗位被替换或降职；日生可指未兑现之未来 |

多因分层：父母账目发动化子克官，与世官自化子克并见，分别查单位文书问题及自身退出。父旺则假破、子月破无力时，处分可能减轻或暂缓；官空时待实空再核，不把“克”一概写成立刻离职。

职业取象：父、蛇、胎组合可取会计；财临应可取销售；二爻财、官、店象可取餐饮；应官为病地、父合妻财可取医院岗位及长辈帮助。职业是候选，不从一个官爻断出确定工作履历。

## 工程、合同、经营

- 工程：世本人、应负责人、父工程。父受日克，虽应生合世仍可能拿不到；应空逢合表示承诺未落实。
- 签约：世应有生表示初始意愿；与世同支的动爻化财克应，另伏官克该爻合应，可取中途换合作人或被绕过。只判关系链，不确认违法或恶意。
- 世化散 → 合作、求婚、开办等求成事项不利；不同事项仍分别取主用，不能见卦名吉便覆盖。
- 商标或证件：父为用，飞空可出，世官值日克飞兄且生父，可取有支持者协助办理。
- 门市前景：应为附属门市、财为收益、子为员工。应官受克，生官之财又被兄局制，取顾客不足与财利受损；世化财克、财化应，可候选转让得款；子化克可取员工走散。
- 开业缺房屋：世化散、建筑父动又散，取筹备难落实；不跨到“开业后财运”。
- 演出或项目：应项目受鬼化兄合克，另暗动爻和日辰再克，取项目难办及资金损耗候选。
- 生意：世经营者、应店址、财财利、官顾客。财空待实空受兄克、又日克，取持续经营不利；官弱合取顾客稀少；世兄动化父合财，可取花费装修改善门面。父多现不机械折算装修次数。
- 养殖：财为利益、子孙为所养动物。财休囚化绝、忌虽化克却得生仍可伤财，再受日合克，取收益不利；子弱墓、源空化克临虎提示健康损耗象，实际动物健康以兽医检查为准。

## 求财、收款、贷款、买卖

- 买入后获利须先确认交易可成。应临日生世可取卖方有意；兄休囚空可取费用压力较轻，不能计算成交价。
- 合同父临勾陈，化财回克又受应同支之日冲，可取出售合同、工程换购等复杂交易；具体内容须结合实际背景。
- 讨款：世静冲克应可取存在不和，未必发展成打斗；财化克但得日扶，可取仍有回款条件。实际安全不由静爻保证。
- 筹资：伏财被飞遮，飞化克后财出，另实际变爻能生财 → 可得资；父临相应卦象可把来源列为长辈帮助候选。
- 古玩出手：子孙作物品可出伏，财临日 → 出售与得款有条件；只判断趋势，不换算成交金额。
- 服务费：财得日合可得，但对应单位之官空被冲脱 → 原渠道难得；另动父化官可列其他业务渠道。必须注明原项目未兑现，不能用别处收入充作本项目成功。
- 借款：应克世表示不愿意，财化克入墓、兄暗克表示困难；子出伏可生财、财克不尽及另两处财不受同兄克，可留最终得款候选。超出原期限就是原期限未成。
- 员工押金：子为离职员工；子与其他爻不伤世，卦内未见闹事链；兄化子生财可取朋友协助取款。兄伤财不能固定推出只退一半，是否应退依据现实约定与法规。
- 贷款财从兄化出且临日 → 朋友帮助的候选。应银行持财临月却受日克，虽应生世也可不成；不能只见月旺财生世就判款到。
- 静卦、世被日合 → 取迟缓；待冲开合后再核支持是否消失。合不直接等于凶。
- 父伏受冲墓、又在初爻显现，临龙雀且贷款目的相关 → 车辆购买候选；无用户背景不擅自确认用途。

## 婚恋关系与阶段

主用：男问关系取财女方、女问关系取官男方，世本人；应可作婚姻关系端。辅助财官只能在证据充分且主题相关时作为第三方候选，不见多现即断出轨。

| 条件 | 取断 |
|---|---|
| 世生应但世化散 | 自己有成婚愿望，后续难落实 |
| 世生合官，而别财临应动进先生官，世又月破 | 有其他关系介入、己方关系受损的候选 |
| 财弱入日墓、不受世生、伏官下 | 女方退避或关系不响应；日月合官可取外部介绍对象候选 |
| 父动化所测对象，处他宫 | 长辈或外人介绍关系候选；不能据阴阳变化精断身份年龄 |
| 用生世却无登记所需之合 | 有追求意愿与不能落实婚约分开 |
| 世用比和、世应无生合，又世被日冲散 | 关系形式存在而缺乏落实条件，退婚候选 |
| 财动化父冲应 | 主动提出变更或解除婚约候选；实际动变若又遭日冲则失权，不以旺暂缓恢复 |
| 应化子生世 | 对方或其家人仍希望维持关系候选 |
| 官生世，却化父冲散弱世 | 对方有意而求测者不接纳，不能只见生世断成 |
| 官月破空，得日合却为空合，又受子动克 | 表面有合而终难落实；空破可涉及过去，需要阶段核实 |
| 官空化空又退、休囚日墓，当前无伴侣 | 优先检查是否旧关系退出，不能把它硬写成尚未来临的新关系 |
| 官自己动空退、世财动生合 | 对方退出与我方仍愿维系分别判断；未来待出空解退另看 |
| 已婚问离：财弱化绝但日生救，官动又遭日冲 | 分别记录财得日生与官动被日冲后失权，不计算“官泄财”；再结合世应用神判断关系走向 |

争吵组合：世用冲克，加兄虎雀，取沟通冲突；墓与伏取回避，不从它们直接确认隐藏配偶。沐浴、桃花、多合、子孙等仅作关系与生育象的辅助，不能确认性行为、怀孕、亲子关系或他人已婚事实。

相貌、年龄差和婚期只在有明确组合与应期条件时表达范围，不输出孤立条件无法支持的精确数字或日期。

## 搬家、出行、来人

- 搬家取父目的住所，应目的地；用化脱且事项喜动，可取搬成。
- 父化子合财，财生应官且官临虎为病地 → 可列为家人方便就医而迁居的象；父弱可取住处条件有限，月日合可取楼房。木数三与三层仅为单例，不固定层数。
- 房屋爻与应所指地点之间隔一爻 → 可作相隔建筑或路径节点的候选，不能仅凭爻差精确测距离。
- 妻来问期：财伏且飞临日克，先难来；官动克飞使财出伏，后可来。元神弱空破临虎、血象等不能直接判断月经或疾病。
- 出行：世应明定位，间爻合世可取同伴；父空可取行李未备，世财弱可取盘缠有限；合世者化退、变六冲可取行程较短。
- 应临勾陈、上爻、宗教相关卦象可取寺庙等目的地候选；方向按支位判断。
- 他地求职可把世卦与应卦分别作现居、拟去处，但要预先确定；现居财回生合绊可取待发收入，拟去处官空冲脱表示该处工作条件不足。

## 健康与现实风险的取象边界

- 世官临虎、相关阶段为病，可列健康忧虑象；元神与用俱受伤、忌伏待出，只表达不利结构与现实核查条件，不推死亡日期。
- 父在初爻临虎、转病地、受金冲，可列长辈腿脚、器械或手术相关候选，不确认病名与治疗必要性。
- 世父空动化克又遭动变爻冲，日生仍有救，可列“受损后有支持”的结构；不能凭此证明有人风水陷害。
- 财父、车辆、马星、低爻、虎、冲散、化墓可组合为交通与就医象，只有现实证据才能确认事故。
- 主问以外若亲爻空动化克并受多处克，可提醒核实对应事项，不以此制造必死恐惧或声称不供祖先、亡灵致病。
- 日生只救仍有作用资格的受克者；日冲动变失权不以日生或旺恢复。旺极群克按合资格作用检查，不转成死亡断言。
