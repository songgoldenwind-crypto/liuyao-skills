# 生克冲合、飞伏、墓绝与空亡

先核 [01-power-order.md](01-power-order.md) 的行动资格、目标优先级及顺序。以下“作用”均指合资格者的实际作用，不把静爻之意当成已发生的生克。

先判真空和原日禁制，再算其他作用。同一作用链只输出一个按权限裁决后的结论。

## 生克

生：木生火、火生土、土生金、金生水、水生木。克：木克土、土克水、水克火、火克金、金克木。

相生可表示帮助、促进、追求；日生可表示外部或上级帮助，回生可表示自身变化带来成就。相克可表示阻止、压制；日克可表示外部压力，回克可表示自身变化造成损坏。回克无有效解救时，原动爻力量被克尽；有解救查转化。群生群克的作用须先受权限限制，不把全部本变爻一律算进去。

## 六冲及日冲

六对：子午、丑未、寅申、卯酉、辰戌、巳亥。冲重于克；冲克同在先论冲。冲可表示快、散、改变、迁移、反复；欲聚欲成之事一般忌冲，欲散欲脱之事可喜冲。

| 条件 | 定性与作用 |
|---|---|
| 动爻或有权变爻冲非空动爻、静爻 | 不论旺衰，按冲散；带克重于不带克；空爻适用下面冲实特例 |
| 动爻或有权变爻冲暂空爻 | 按冲实有用，仅解除暂空；静爻仍静不获得主动权，动爻恢复其原有资格，再查作用利害；不能绕过回头、跨爻与作用顺序限制 |
| 静冲静 | 势冲，有冲意无冲力 |
| **原日辰冲非空静爻** | 不论旺衰，均暗动；分旺暗动、衰暗动，不把衰静日冲叫日破 |
| 日冲明动爻 | 不论旺衰冲散，并殃及其变爻；动变均失用 |
| 日冲变爻 | 不论旺衰冲散，也称日破，并殃及原动爻 |
| 日冲空爻 | 不论旺衰动静，冲脱；动空被脱连带变爻 |
| 日冲变空爻 | 冲脱，连带原动爻 |
| 日冲伏空爻 | 冲脱失用 |
| 日冲非空伏爻 | 带克不出，不带克可出 |

冲散、冲脱：在当前作用层记失权；原日造成者为最终失权，旁动造成者仍须核验后续较高层变、日是否存在明确冲合解救（见下表）。最终失权者原计划在本事上不中用；可取转迁、移动、改换目标、事情已经结束之象，不自动视为凶事发生。

暗动无变爻，表示由外力使令而动，不能替它补造变爻。衰暗动仍可生克，落实快慢再按期候观察；应期取合暗动支或合日辰。旺衰仍取原月，不以流月重新改原局成败。

**暗动默认权限：**采用专门日冲口诀的限制：暗动可以生克，不独立发动冲合；三合章节明列“二明一暗”，作为明确特例允许参加。总功能表中“暗动有冲合权”的概括不另执行。衰暗动仍有生克资格，旺衰只表示程度；“待旺”仅作原局可用之力落实的期候，不另判当下无权。
**日冲与动冲空不可混用：**空逢有权动爻或变爻冲为冲实有用，空逢原日辰冲为冲脱无用。前者是一般动冲散的空爻特例，后者不属于暗动或流时改判。先分原日辰、动爻、有权变爻，再判真假空；与 [04-reading-procedure.md](04-reading-procedure.md)、[05-pattern-language.md](05-pattern-language.md) 及 [12-execution-rules.md](12-execution-rules.md) 联用。

**真空优先排除：**先判空化空，以及静空休囚且未得原日生助者为真亡；真亡不受动变冲实、动生或流时出旬恢复。其余暂空才进入动变冲实或日冲脱判断。
## 冲合先后

| 本阶段关系 | 后阶段关系 | 过程 |
|---|---|---|
| 本卦冲 | 变爻合 | 先散后成 |
| 本卦合 | 变爻冲 | 先成后散 |
| 本卦冲 | 日辰合 | 先散后成 |
| 本卦合 | 日辰冲 | 先成后散 |
| 旁动合本爻 | 本变冲 | 先合后冲，成后散 |
| 旁动冲本爻 | 本变合 | 先冲后合，败后成 |

## 六合

子丑、寅亥、卯戌、辰酉、巳申、午未。合表示聚集、协作、绑住、慢、久。子丑午未为近短合，卯戌辰酉为远久合，寅亥为中合。

- 生合、克合先论合；合中克是结合内的矛盾，不能写成先合后克。生合比克合有利。
- 刑合可取合作中对抗、恩怨相交；不因带克或刑就抹去合的束缚。
- 午克申遇有效戌土可转克为生；巳与申已有合，则不能用戌土把这一合转掉。
- 动合静为合起，表示助人成事。日合静也合起，但不产生主动生克冲合权，不能叫暗动。
- 日合动为合绊，暂不能动，但取迟缓成事；应在冲开时。动合、化合也有暂绊与费力延迟之意。
- 空上逢合：形式好而内容虚、约定难兑现；不因合就判成。
- 合旁爻，成合之事先属旁人；合世先看自身。吉事宜合自己，凶事可利合应方，仍须看所问对象。
- 求功名事业可喜用合；官讼合可难结案，行人合绊可难归；财局、子孙局有利求财方向，兄弟局可阻财，父母局可对应家宅。

问行人何时动身或归来，默认合绊则未动、待冲开；问关系是否促成才用喜合。按具体问题分流，不再用笼统“行人喜合”覆盖行动被绊。

## 三合

四局：申子辰水、亥卯未木、寅午戌火、巳酉丑金。

成局须三支齐全，并满足其一：三爻全动；二明动加一暗动；二动加日辰；二动加其中一个原动爻自己的变爻。其他不属这两个原动爻所化的旁变不得凑局。月令、静爻、伏爻不得参加；两支不得算成局。

成局条件齐备后，空亡、月破、入墓、日克不直接取消成局资格，但可暂不能发挥，待出空、出墓等对应条件。破局条件：日冲散脱局中动变；旁动或有权旁变冲局中一支；局中一爻化克且无转化。

成局按化局五行作一条主作用；成员原五行与六亲保留供取象、判破局，不对同一目标额外累计一遍生克。真亡成员先排除；其余暂空、暂墓按出空出墓条件等待。未成局按常规；半合仅取象，不主吉凶。

三合取多人结伙、交涉聚会；水局可取斗争、木局交易和合、火局财喜、金局隐情，须有具体事项再用。

## 刑、害、破

三刑组：寅巳申、丑戌未；须三支俱全、卦爻俱动，或两个发动刑支与日辰凑齐三支。“一刑爻与日和二刑爻成刑”归入后一条件：一爻发动、另一爻也发动、日辰补第三支；静爻不能补位。

刑的吉凶随旺衰、刑我刑他及有无制救；少一仅取矛盾。辰午酉亥自刑不主吉凶，只取自作自受、烦恼之象。子卯按贪生忘刑处理，刑义仅取象。寅巳申可取困难、对抗中合作，丑戌未可取阻隔、伤病之象，不凭刑断事实。

六害：子未、丑午、寅巳、卯辰、申亥、酉戌。须先有合、再被第三支冲破才论害；仅见两害支而无合不另论害。例：子丑合被未冲丑，才从子未关系取被干涉之害。其余相生相克仍按本来的生克。

六破：子酉、丑辰、寅亥、卯午、巳申、未戌。六破、六害不另增吉凶权重，只在生克冲合框架中取失约、阻隔、破坏等象。

## 进退、伏吟、返吟

| 项目 | 规则 |
|---|---|
| 进神 | 亥化子、寅化卯、巳化午、申化酉、丑化辰、辰化未、未化戌 |
| 退神 | 子化亥、卯化寅、午化巳、酉化申、辰化丑、未化辰、戌化未 |
| 近事 | 旺相化退暂不退；休囚化进暂不进 |
| 利害 | 吉用、原神宜进；忌仇宜退；欲散之凶事衰退可有利 |
| 卦伏吟 | 乾兑、震巽、艮坤互化，仅取原地踏步、欲动不能等象 |
| 爻伏吟 | 子化子等同支重合，涉及作用权暂停，须查解除条件 |
| 卦返吟 | 乾巽、震兑、坎离互化等，仅取反复迁改之象 |
| 爻返吟 | 子午等本变对冲；兼回克重，不带克可仅反复而无大凶 |

伏吟与返吟的名字不能单断最终凶，仍查解救。伏吟内卦偏内事、外卦偏外事。返吟可取财聚散、婚反复、出行折返、迁而再迁；行人失物可有返回之象，须再核用神。

按所求对象定进退利害：吉用、原神进为助，忌仇进为患；所求是解除凶患时，凶用退才有利。进退应期统一见 [03-subject-timing.md](03-subject-timing.md)。伏吟仅凭名称不定凶，但爻伏吟失权及具体解救影响成败，分别处理。

## 飞伏

飞为显、表、外、上、左、明；伏为隐、里、内、下、右、暗。还可取飞将来、伏以往，或表面与内情；“飞假伏真”是取象角度，不能断定外在事实均假。

先看伏神能否引拔。拔为冲克飞、解除覆盖；引为生合伏而出；飞空或休囚无气入墓时可自出。出伏才进一步查其对旁爻作用。

闭伏条件：日克伏、日墓伏、日冲脱伏、日冲克伏、日合克伏、飞克伏、飞墓伏。

开伏列举：日克飞、脱飞、冲飞墓、合生飞、墓飞、生伏、值伏、冲飞；动克飞、冲飞、合克飞；有权旁变克飞、冲飞、合克飞、墓飞；飞化克、绝、墓、冲；飞空或化空；飞生伏、伏生飞、伏克飞。

### 开闭伏默认判定次序

1. 先排除伏神真亡、原日冲脱；这两项不得因飞空或飞受制而恢复。
2. 再查原日对伏的克、冲中克、合中克、墓。原日禁制高于飞与旁动变的开伏条件；有日禁时保持闭伏。日墓记暂闭，流时冲墓只定其既有出墓期，不重写原日成败。
3. 无日禁时查飞克伏、飞墓伏。有这种覆盖，必须先有合资格的日、动、变作用解除飞的覆盖；伏生飞、旁生伏不得直接越过飞克墓而宣布开伏。
4. 障碍已经解除，或本无覆盖障碍，再采用日生伏、日值伏、日冲伏不带克、飞空及合资格引拔等明确开伏条件。开伏后才接受旁动变生克，不以旁生闭伏为自我循环的开伏理由。
5. 日合生飞不单独构成开伏。“空化空”在开伏条件中只按飞空或飞化空解除覆盖，不恢复伏神自身真空。
6. 飞伏之间无论动静仍可按专门规则建立生克关系，但不得绕过真亡、日脱与原日禁制。多个开伏信号不抵消一个尚在的高级闭伏障碍。

取象例：问财伏子孙可看隐藏财源，伏兄可看口舌竞争；官伏而再出可看旧事再起；捕逃以飞为捉拿方、伏为逃者，飞克伏趋捕获、伏克飞趋难捕、生合趋难寻。伏藏、空亡、无子孙等不能直接转换为医疗绝望或死亡判断。

## 墓绝

十二宫按日支关系查；金木水火表见 [10](10-branches-trigrams.md)。土在生克裁决中不用十二长生；明确要求寄生十二宫时，才按阳土生寅、阴土生申作阶段取象。长生、冠带、临官、胎、养为进气，沐浴、病、死、墓、绝为退气；帝旺近事可速成、远事可能滞散。进气推动吉或凶之对象，并非一概吉。

- 土无长生、无绝为本体系主张；金遇巳不论长生而论火克金。
- 土化巳，判吉凶论回生；提取象时又允许论绝，与“土无绝”分理象记录，不能合成土被绝而不受生。
- 金见丑日或丑爻，吉凶论土生金，墓仅取象，不按墓剥夺受生。
- 绝位按完整表取水绝巳、金绝寅、火绝亥、木绝申。午亥、寅酉、子巳、卯申的成对口诀可分别补口舌、文道、妇女、车马财等象；“近绝”只作程度描述，不新增绝位或覆盖完整表。
- 有日墓、动墓、化墓、飞墓，无年墓月墓；不以旺衰分墓库，不以随鬼入墓直接断凶。
- 实际入墓者暂停主动和受作用权；动冲墓或流时冲墓为出墓应事条件，飞墓、进退墓亦需冲。
- 静爻出墓仍静，不因出墓获得动能。墓可取隐藏、失自由、完成结束，吉凶按所问。

## 空亡

旬空按原日干支查。先分真亡与假空，再分谁来生克冲合；不能见空即删除，也不能见流日出旬就认定一切恢复。

| 条件 | 判断 |
|---|---|
| 静空休囚，未得原日生助 | 亡，动爻来生也无用，所求不成 |
| 用神空化空 | 真亡，不受作用也不主动作用，事无实 |
| 静空旺相 | 暂空，出空填实时再应已受之生吉或克凶 |
| 动空，不论旺衰 | 暂空；旺者待出空填实，衰者兼待旺相条件；不持久、虚张声势之象 |
| 衰空得日辰生助 | 暂空而非真亡，是静空休囚条目的明确例外 |
| 合空 | 外好内虚，承诺难实现 |
| 日冲空 | 冲脱失用、转移目标，不作冲实恢复 |
| 有权动变冲暂空 | 冲实有用；先核行动资格，恢复后再按所问判断利害 |
| 动爻克暂空，称伤空 | 当前空期避开该次伤害，不等于出空后一概吉；恢复时复核既定有效克链 |
| 空而无其他生克合，称自空 | 失踪、无内容等象，条目断凶，出空应事 |

冲空按来源执行：真亡先失用；暂空遇日冲脱、遇有权动变冲实。伤空按两个阶段输出：空期暂避伤，出空或填实后若原局有效克链仍在则应其不利；不把暂时避伤当作整件事最终吉。

真空表示所取对象不落实或已退场，最终利害仍按求得／求去：官职真空不宜求得，病事或拟脱手物真空可作退出之象，但须结合相应专题条件，不能只凭真空宣称治愈、售出或得款。

暂空一般减弱吉神之吉、凶神之凶；消灾之问可因凶用空而有利。近事忌现爻空、远事忌伏空是范围提示，不盖过真空假空及具体利害。
