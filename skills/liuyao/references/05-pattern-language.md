# 条件断语与关系链

通用条件与单例延伸分开；涉及严重人事的含义均为象义候选。

## 生克、救应与成败

| 条件 | 判断 | 限制 |
|---|---|---|
| 主用得到有效生合 | 有成事条件 | 空合、合绊、无力生到时另论 |
| 主用受旁动、旁变冲 | 事情散失、不成或终止候选 | 按本、变、日先后查后阶段作用；不与日冲动变混淆 |
| 原日辰冲主用动爻或实际变爻 | 动变失权，本事失用 | 不论月旺月衰，不以日生、旺暂缓恢复 |
| 主用化克且受其他爻克 | 不利加重 | 各克须说明资格、来源及时间，不按数量机械判死 |
| 受克但得日生 | 尚有作用资格时可有救、克不尽，先不利后转 | 不适用于已经日冲散、日冲脱而失权者 |
| 用神临日 | 取有力、克而未伤 | 仍须检查化退、合散及期限 |
| 用神化克，忌神也化克、化散 | 先看忌神是否还可伤用 | 忌受制却另得生，可能克不尽而仍有克用能力 |
| 元神被制不能生用 | 不能救用 | 用旺也须查来源与作用，不直接当成事 |
| 财旺而被成局兄克 | 可取损失较重 | 旺财不自动等于获利；不折算具体金额 |
| 旺极同时群克 | 多方压力集中，不利 | 不以数量评分，也不据此断死 |

## 空、伏、合、墓

- 空合 → 约定虚悬、关系未落实；有关婚约、工程、合作时不能把有合直接判成。虚悬不等于已经证实对方欺诈。
- 空爻暂不受克 → 不表示永久无伤；出空、填实时再查克是否兑现。
- 空又化空 → 作真空；结合化退、休囚、入墓，取退出、不见或难落实。
- 伏神受飞克 → 暂不能出现或发挥；飞神化克、被制、空亡 → 可产生出伏条件。
- 伏用出后有实际生扶 → 可成；出后仍受有效克 → 仍不利。
- 伏神旺、飞神空 → 保留待冲出后改善的可能，不把未出的作用算成当下已有。
- 动财化回头生但逢日合绊 → 有财的条件存在，当前未到手。
- 用入墓 → 可取躲避、收起、不见、受阻；结合阶段判过去或未来，不直接当死亡。
- 化入墓且本体旺、另有日救 → 不只按入墓断绝。
- 父母与世或用构成合、生、冲的关系 → 可对应合同、婚姻登记、房屋等；先依据所问选义。

## 动变与自主性

- 用神自己发动化克、化空、化退 → 可取本人主动退出、辞职或不愿继续；不能离开主用身份泛化为“自己害自己”。
- 外爻发动来克主用 → 取外部原因；自化克与外部克并见，要分别解释两条原因，不能重复写同一件事。
- 克世的爻后来化出生世者 → 先不利后有支持的候选，查前后作用是否成立。
- 化进 → 表示该作用趋强或延续；子孙化进克官可表示岗位压力增加，财化进生官可表示追求持续。
- 化退而旺 → 暂不退；休囚再退可视为已退或将退，须依当前阶段。
- “旺而暂不退”是进退条件，不是日冲散的例外；日散动变仍失权。
- 化克不等于彻底消失：被克之忌另有变爻生、日扶时仍可能克用。
- 用神多现：静用可表示原有状态，动用表示发展趋势；衰退受伤之用可表示旧经历，另一用可表示未来。需说明分配理由。
- 静爻可显示意愿、尚未行动：妻财静而生应官，可取想去该处工作；世静冲克应可取不和却未见实际行动。静不等于所有现实行为都不会发生。

## 世应、间爻与移位

- 世为本人，应依题目可为对方、对方单位、项目负责人、营业门市、地点或婚姻关系端，不预设应永远同义。
- 世生应 → 我方有意；应生世 → 对方支持或有意。双方有意不能覆盖合同、资金或用神受损。
- 世克应或应克世 → 意向不合、压力或不情愿；是否能实际伤害还看动静与日扶。
- 世用比和但无生合 → 部分婚例取由人撮合、意愿平淡或登记难成，不把比和一律看作相爱。
- 间爻合世 → 在出行例取同行者或中介参与；间爻化退、总体化六冲可取同行或行程不久。
- 同支移位：实际动爻与世同支，可作世的延伸；日支与应同，可把日作用联系到应方；动爻化出与世同支，可取行动最后落在本人。
- 移位只说明代表联系，保留原卦盘位置。不得因此改写静爻动变、六亲、空亡或让任意两爻自动等同。
- 静位的虚化不参与作用；实际动爻化出的变爻可按资格跨爻生克。

## 六神与位置的组合语言

| 已有作用链 | 可选象义 |
|---|---|
| 兄临朱雀、白虎且世应有冲克 | 口角、争执、情绪激烈 |
| 兄临玄武发动克财，再化父母单位 | 隐性财务损耗、公司款项问题；不据此指认盗窃 |
| 官与日财合，父母公司又受损 | 管理与资金关系待查；不直接认定贪污 |
| 财生官、与世争先，临应或动进 | 第三方资源或关系介入候选；先辨是感情还是业务 |
| 用空、伏父、父临玄武又有婚姻关联 | 隐而未明的婚姻信息；不确认已婚或不忠 |
| 主用化父母、父与登记宫相关 | 合同、证书、婚姻手续、入单位或入院等，按题目限定 |
| 官伏父下、父为账、蛇为技艺、胎为计算 | 记账、会计一类职业候选 |
| 父居乾卦火支、二爻、勾陈 | 金属、电、家用、搅拌等组合成家电行业候选 |
| 二爻财、火官、勾陈店、养地 | 饮食店工作候选 |
| 应鬼并为所测人的病地 | 医院地点候选，不直接诊断病情 |
| 父初爻临虎、金冲 | 脚腿、车辆、器械或手术象，依实际问题选择 |
| 父世同宫、马星、低爻 | 自用车辆候选；不推定具体事故已经发生 |

父母或卦象可取长辈，阴化阳可取男性帮助者，阳化阴可取女性，五六爻及旺相可取高大，兑宫金支可取脸形。只作辅助象义，不给确切年龄差、相貌或人格断言。
