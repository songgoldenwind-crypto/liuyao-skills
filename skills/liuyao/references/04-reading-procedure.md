# 断卦前提与步骤

## 前提

- 先明确实际所问，不问、不动、无事、无异状时不强行造题起卦。心动起卦也须记明触发背景，随意念头不冒充明确事由。
- 先定期限。问今日只论今日，问本月只论本月；未来条件超过期限时，不算当前问题已经成功。
- 先定阶段。婚恋区分尚未认识、正在交往、已婚；工作区分未任、在任；疾病区分新近、久病。相同动静在不同阶段意义不同。
- 本体系认为卦中首先带有摇卦人自己的信息；代占时仍须把摇卦人与被测者分开，不直接把世爻改作所有被测人。

## 六步顺序

1. **申明主题。** 分成“人与事、人与人或事与事”两个关系端。复合问题先后有依赖：先判断能否买到，再判断买到后能否获利；前项不成立，不把其他财利算作这次交易成功。
2. **查空亡。** 查伏神、本卦、实际动爻所化的变爻。原静爻在完整变卦盘上显示的另一支，不单独纳入变爻空亡。
3. **查日冲。** 按下表逐项标记，结合 `02-interactions.md` 的开伏与日冲失权规则；不能只用步骤段的简写覆盖完整条件。
4. **列用神。** 先主用神，再辅助用神；统计本卦、伏爻、动爻化出的用神共几现，静爻对应的变卦标注不计。看每一用神得几生几克、旺衰及最后有无救应。
5. **定吉凶。** 基本纲领是主用得生合趋成、受冲克趋败；但必须经过空合、冲脱、旺不退、日救、克不尽等例外复核。
6. **提取象。** 用辅助用神解释主用神的来因、经过、结果。六亲、六神、地支、爻位、内外卦、卦宫、卦象、十二阶段等共同限定物象；卦名与爻位不得推翻主用神的成败。

## 日冲分类

| 被日冲对象 | 本体系标记 |
|---|---|
| 非空伏神 | 日冲不带克可出；带克不出 |
| 空伏神 | 冲脱 |
| 本卦非空静爻 | 暗动 |
| 本卦非空动爻 | 冲散，并殃及其实际变爻，动变失用 |
| 本卦动空爻 | 冲脱 |
| 实际变爻非空 | 冲散，并殃及原动爻，动变失用 |
| 实际空变爻 | 冲脱 |
| 本卦静空爻 | 冲脱，不作冲实 |

必须区分冲的来源。旁动、旁变造成的冲，按“本卦→变爻→日辰”的先后查后阶段能否改变过程；原日辰冲动爻或实际变爻则不论旺衰彻底失权，不再用月旺、日生或“旺暂缓”恢复。伏神符合出伏条件后还须查生克资格。日合或日生救助其他尚有资格的爻，不等于把已经日散、日脱的爻救回。

## 动静与阶段

| 事项 | 基本喜忌 |
|---|---|
| 已经相处的婚姻、在任工作、二宅、放债、失物、求长久稳定 | 一般喜静忌动 |
| 讨债、生育、脱货、脱狱、消灾散病、出行搬家、未婚求偶、找工作、调动 | 一般喜动忌静 |
| 认识对象但关系尚未开始 | 静可表示尚无进展 |
| 关系已稳定并问能否维持 | 静可表示无变故 |

此表是阶段倾向，不越过主用实际得失，例如动而化散的求职不能只因“喜动”判成。

## 主用、次用与全局复核

- 主用清楚后才看其他爻，避免辅助信息喧宾夺主。
- 静爻、伏爻都要检查，但不是每个象都要写进答案。先判主要成败，再看与所问有关的重要次级风险。
- 单爻象义不足时用多爻关系组合。不能见一个桃花、玄武、白虎就确认婚外关系、犯罪或病伤。
- 外应记录为现场线索，与卦内主线相合时可辅助；不把牌子掉落之类现场现象当作事业成败已被决定的证据。
- 本卦可描述开始和已有状态，实际动变可描述发展趋向；用神多现时可分原有、过去与未来，但必须说明根据，不能任意挑爻。
- 月内已衰退、日上入墓不见可取过去；旺相、日生、未出空可取未来。必须结合所问期限和事实核对。

## 表达

先给结论，再给最关键作用链。面对非专业用户，术语后紧跟实际含义。不要用“断不成，但照我解法又可成”制造不可证伪的两头说法。

清楚表达已经具备判断条件的部分；缺少影响结论的输入就明确指出。疾病、死亡、婚育、犯罪及隐私只表达术数象义，不直接确认现实事实，不归咎亡灵、祖先或因果报应。
