# 用神、世应、应期

用同一条作用主线输出相容的时间范围；没有成事或解除阻碍条件时不报精确应期。

## 五神与欲成欲散

用神为所问对象；原神生用；忌神克用；仇神生忌且克原；喜神克忌。仇神不是耗用，喜神不是泄用，不借耗泄解释五神。

| 所问目标 | 原神 | 忌神 | 仇神 | 喜神 |
|---|---|---|---|---|
| 吉用：想成、想得，如求财、成婚、升职 | 吉 | 凶 | 凶 | 吉 |
| 凶用：想散、想败，如疾病、牢狱、忧患、敌害 | 凶 | 吉 | 吉 | 凶 |

先明确用户希望什么结果。不能把“离婚”等事件名称永久归凶用：若所问是希望分离，聚散的利害须随目标分明。生用不总吉、克用不总凶。

## 按事项中的身份取用

同一个人随具体关系不同可取不同六亲；不能仅用姓名、性别或称谓固定一爻，也不能把别的体系“凡代占皆世”移入。

1. 自占自身损益，以世为用，例如自身出行、安全、身体、调动。
2. 自占事物，世为本人，另取代表事项的六亲；求财以财为事用，工作官鬼、学业文书父母等按现实角色取。
3. 代占他人，以亲属、辈分、职务、身份取人用；无尊卑关系且不深交者等可取应。
4. 代占他人的事项，同时取人用和事用；例如兄弟财运，人取兄、事取财。人事同一六亲时，以事为主，例如妻子财运首看财运。
5. **代摇不同于代占：**朋友先发起占自己事的意念，只请别人代摇，世为该朋友，摇卦者只是助手。必须明确发起意念者，不能因手是别人摇就改世为摇者。

匿名反例：夫妻打牌问谁赢，是竞争系统，世为我、应为配偶；问夫妻关系，则取世和财官相应角色。问祖父等长辈直接取父母，不用“生父母者”为祖父再层层重排。真假六亲、移亲等只在明确多人或终身范围另有规则时使用，不默认套入单事占。

## 多现用神

本卦、伏神、变卦、年月日中相关用神都登记，不以空、破、旺、静或离世近任意舍一。时间中的用神可承载象与期，但年月并不因此取得卦爻生克权。

登记后按实际问题分主次，不要求把所有闲象罗列进结论。

| 条件 | 取法 |
|---|---|
| 同一事、两个同类六亲 | 可代表内外两处、前后两个状态，不自动认定两个人 |
| 两个实际对象、同类六亲两现 | 可分别代表，例如父亲与母亲；对应不明时不猜 |
| 两个实际事项、只一个相关六亲 | 可共用，如妻子与离婚财产均财；分别解释作用所指 |
| 两现都动 | 按已知起终点、内外世应分角色，再分别判发展与时间 |
| 一动一静 | 静为原来或过去状态，动为发展趋势 |
| 两现都静 | 都看，按内外、远近、我他、家内家外等实际结构定位 |

搬家：世方父母为原家，应方父母为目标家；目标家判断搬去后的发展及对应期，原家看旧环境、搬因和离开时机。邮购物品：应方父母为寄出的书，世方父母为收到的书。

“两现只能一内一外或分世应方”是所述解释，不能硬改排盘使其符合；真实盘不符时说明此条覆盖不足。

## 世应与间爻

世为本次的主，应为主所指对象，不一定都是人。自己出行：世本人、应目的地；下雨：世地、应天；比赛：世我队、应他队；房车：世本人、父母为物。

财在世位先取我方财，在应位先取彼方财，再查作用能否转归我方。主受伤一般影响全事，但不能用“世凶一切凶”掩盖代占专看他人用神或凶用欲散的明确条件。

世应生合可取相投，冲克可取不睦。世应皆空、空合可取双方无实、虚约难成；结合真空假空判，不直接断人物不诚信事实。世空世动可取我方意愿不足，应方反变可取对方变化。

间爻为世应之间两爻，发动一般表示中间阻隔，但其实际生合也可调停，须看具体关系。

| 占问 | 间爻角色与判断 |
|---|---|
| 婚姻 | 介绍人；世生合间为世方亲，应生合间为应方亲，双方生合则两家皆亲；阳男阴女，衰墓年长、生旺年少仅作象；空化空可换介绍人，两间俱空可无介绍人；生合世应能调停，刑冲克害世应趋阻挠；世应冲克间可双方怨介人 |
| 官讼 | 证人；生合世偏我、生合应偏彼，冲克谁与谁有隙；旺助应、衰助世为彼方证力强；静生应仅态度、动克世为实际不利；日辰或官制间可取证言不获信，间空可证词不实；近世近应仅辅助区分证人方属 |
| 营谋交易 | 经纪、中介、批发市场 |
| 借贷 | 担保人 |

间爻静不能因“生应”就赋实际生助权；证言真假、犯罪及人格需现实证据，象法只描述候选关系。

## 应期先决条件

先按 [01-power-order.md](01-power-order.md) 完成原局本→变→日判断，锁定主因与结果，再找何时应。流时只标应期，不重新摇动原局性质。

1. 明确所问期限与远近缓急：终生按年、年内按月、月内按日、日内按时；远事年月，近事日时。
2. 找真正决定成败的用神或阻碍、解救点；排除无关信息，记录其所需值、合、冲、出空、出墓等条件。
3. 对照各候选条件求重合时段；必要时先年后月再日时，不能脱离问题硬细到日。
4. 用在原日前可取已过、在日后可取未来，但地支循环必须结合所问期限判，不把每支都任意配过去或未来。
5. 原时、干支、用神状态不足以定位时间时，只给能够确定的范围，不报公历日期、旬空或精确时刻。

快慢分触发和完成：冲、现、动偏快触发，合、静、伏偏慢；有刑克阻碍则完成延迟，不能以触发快推成事快。旺衰仅作程度辅助，不单凭旺动报当天。无法找到解除阻碍条件时，不给完成日期。

## 条件应期表

| 原局条件 | 候选应期 | 限制 |
|---|---|---|
| 用静 | 逢值或冲动 | 流冲是应期标志，不重新制造原日暗动 |
| 用动 | 逢合、逢值，或变支值 | 查合绊与事情成的不同阶段 |
| 用被合绊 | 逢冲 | 冲开之后还需看所释放者利害 |
| 暗动 | 合暗动爻或合原日辰 | 不补造暗动变爻 |
| 太旺 | 入墓时 | 原局金遇丑优先论生等特殊规则仍有效 |
| 入墓 | 冲墓 | 静爻出墓仍静 |
| 假空 | 出空、填实；一般应期条亦列逢冲 | 原日冲空为脱，不能把它读成冲实；真亡不因出旬恢复 |
| 化进 | 本变支逢值或合 | 休囚近事不进 |
| 化退 | 本支或变支逢值；已有合绊须先取冲开 | 单有合而无其他落实依据，不另报退成之期 |
| 旺用受克 | 冲去克神 | 日辰至高不可被卦爻反制；此处只能结合可解之克源，不凭候选日改掉原局日克 |
| 月破但未被原日散脱、真亡 | 逢值或合 | 仅为原局仍可成事项的落实期；原日冲散冲脱已失用者不进入恢复候选 |
| 动化变 | 变爻逢值 | 先确认动变未散脱失用 |

不执行“俱不动必当日”的无条件读法。若原局已确定以日为单位、明确用动支为期，才可从原日按支序寻找期限内下一次值日；“寅日卯为第二日、辰为第三日”是含起点计数，不代替可靠公历换算。

辅助时间尺度：太岁并临取年内，节气取当月，四立取季度；首要用神空而发动可先取本旬，君主用取朝暮，气取约十五日，候取约一周。这些只用于限定已有成事条件的时间范围，不改变原局结论；多个尺度并见时，以决定成败的用神及所问期限为主。

## 过去、现在、未来

默认优先级：用户已知事实与占问期限 → 主因所定的原时支序 → 本变发展阶段 → 旺衰/爻位辅助象。低级象与高级时间相反时舍弃低级象，不再并列互相矛盾的过去未来结论。

- 旺动偏现在，相动偏未来，休囚死动偏已经发生或已失势；事情可以尚未结束，仍不成气候。
- 按动支与原年/月/日/时支的前后序比较：申年见未动可指过去一年、申指当年、酉指下一年，其他层级类推并结合期限。
- 初爻可指过去或刚开始，三四爻指现在或发展中，五六爻指未来；二爻结合所问阶段判断。
- 本卦现在、变卦未来是象义；本→变→日仍是裁决流程，不能以未来变卦绕开日辰。

## 象法与解救范围

先理后象：理法判断何处受生克与能否成事，象法限定是文书、财物、工作或关系。同支可表示本变动静之间的代表联系，用于追踪来龙去脉，不改变实际盘位，也不单独决定吉凶。

解救先看原卦有无实际转化条件；有条件再谈相应时空调整，无条件不承诺可解。宗教修持、施法及疾病治疗不属于可由此卦法验证的作用规则，不写成测算结论。
