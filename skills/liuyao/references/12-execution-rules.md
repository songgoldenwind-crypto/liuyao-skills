# 全局执行规则速查

本文件用于跨模块查核。同一卦只按一条相容的作用链执行。

| 主题 | 执行规则 |
|---|---|
| 月令与日辰 | 原月定旺衰背景，原日为最高作用层；年时只取象与应期 |
| 衰动 | 极衰无动权时不主动生克；实际发动且未失权时可以作用旺静 |
| 暗动 | 只生克，不独立冲合；二明一暗成三合作为专门条件 |
| 动静目标 | 动爻先作用有关系的动爻，不绕过该目标直接作用静爻 |
| 变爻 | 有回头生克冲合时仅作用原动爻；无回头关系时才按资格向外作用；变不作用变，虚化无权 |
| 真亡 | 空化空、静空休囚且无原日生助者失用，不受动冲或出旬恢复 |
| 暂空 | 日冲为脱；有权动变冲为实。冲实只解除空，静爻仍无主动权 |
| 日散日脱 | 原日冲动变或冲空造成最终失权，不以月旺、日生恢复 |
| 较低层冲合 | 旁动冲造成阶段失权；较高层变或日有明确合救时，以高层作用裁决 |
| 三合 | 成局作一条主作用，成员原支保留取象和判破局，不重复计力 |
| 开闭伏 | 真亡、日脱先排；日克墓等禁制优先；再解除飞克飞墓；最后判断引拔 |
| 墓绝 | 金逢巳论克、逢丑论生；土在生克裁决中不用长生绝，寄生宫仅作明确请求下的阶段象；墓先作状态及应期条件 |
| 进退 | 按所求对象定利害；旺近退暂缓、衰近进暂缓 |
| 应期 | 先定主因与期限，再找值、合、冲、出空、出墓或解绊条件；超过期限不算期限内成功 |
| 流时 | 用于落实原局，不替换原日原月重新翻判 |
| 耗泄与数值 | 不设耗泄作用，不以比例加权，不把卦数直接换算金额、寿数或概率 |

执行顺序：**取用 → 月令旺衰 → 空墓散脱 → 本卦动爻 → 实际变爻 → 原日裁决 → 象义 → 应期**。任何快捷口诀都不能越过用神、权限和作用顺序。
