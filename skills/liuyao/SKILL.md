# 六爻分层断卦

按本体系的取用、作用资格与先后顺序推断，保留具体条件，不把口诀中的吉凶写成已经证实的现实事实。一个问题先完成一条主要作用链，再按需补细节。

## 输入

利用已有的占问、求测立场、自占/代占/代摇区别、时间范围、起卦时间及卦盘。只有影响所问判断的信息缺失时才追问；局部规则比较无需强求全盘。

卦盘核对：初爻至上爻、阴阳老少、动爻、本变卦、纳甲、六亲、世应、伏神、月令、日辰、旬空。静位在变卦中的标记是“虚化”，不能把变卦六个爻都当有作用权的真实变爻。日期或日柱未给出时不计算旬空。

起卦与装卦读 [07-casting-calendar.md](references/07-casting-calendar.md)。优先调用`liuyao-paipan-code`生成本变卦、纳甲、六亲、世应、六神、伏神候选、旬空和基础神煞；公历补盘采用节气月界和指定日界。调用前先确认`liuyao-paipan`命令或源码入口可用；若当前 Agent 未安装排盘模块，则使用用户给出的完整卦盘，只追问影响判断的缺失项，不臆造本变卦、干支、纳甲、世应或旬空。排盘输出只提供结构，断卦仍执行本技能的规则。月支缺失时可核对基础盘，但不判断月令旺衰。

## 固定执行顺序

1. **定所问与用神。** 读 [03-subject-timing.md](references/03-subject-timing.md)。先区分想得到/促成之事与想解除/脱离之事；再定世应、人物六亲、事物用神。代占按问题中的关系取人，代摇才按发起意念者定位世爻。物品能否卖出与是否得款分开。
2. **标状态和权限。** 读 [01-power-order.md](references/01-power-order.md)。原月令定旺衰，原日辰及有效动变定实际作用；旺衰与强弱分别记录。标日冲暗动、空亡真假、开闭伏、真实动变与虚化。日辰最后裁决，不妨碍先识别由日辰确定的这些状态。
3. **演本卦。** 读 [02-interactions.md](references/02-interactions.md)。先查有权动爻之间的实际作用，再查对静爻的作用；先冲合后生克，结合贪生忘克、贪合忘冲及各自条件。没有作用资格者只取象，不加入生克链。
4. **演变爻。** 先查变爻对原动爻是否有回头生克冲合的关系，依规定决定能否作用异位动爻、静爻或开伏。不得让变爻互相作用，也不得让低层爻反过来制变爻。
5. **以原日辰裁决。** 对变爻、动爻、静爻按层次核验，确定前述生克是否被制、被救或冲散。保留“先受克、后得生”“有伤而克不尽”等过程，不用最终一个吉字抹去全部阻碍。
6. **取象与应期。** 先定此问题的趋势，再读 [04-reading-procedure.md](references/04-reading-procedure.md) 的表达与查核流程，按需取象。应期规则见 [03-subject-timing.md](references/03-subject-timing.md)：流时用于落实原局事项，不另换日辰或月令反复翻转原判。

## 体系边界

- 日辰权力最高；年月时不能代替日辰实施生克冲合。月令的旺衰、月破状态与日辰冲克不是一回事。
- 此法不用“耗泄”作为独立作用；金生水不能倒写成水主动泄金而伤金。
- 静爻、虚化、闭伏无一般对外作用权，飞伏之间另有专门例外。无权不等于没有象义。
- 同一用神两现应按内外、前后、动静和实际对象分工，不能任意舍破取旺或舍旺取破。
- 空、散、墓、绝的意义取决于对象和所求：求得之物消散与欲除之患消散，结论方向不同。
- 不引入另一套“全局调平、双原、流时重新定强弱”的规则覆盖本法。用户要求比较时，分开呈现两套推演。

## 输出

直接给：**所问判断 → 用神与作用链 → 过程/应期 → 必要条件**。只解释决定结论的节点。若仅问规则，直接作条件比较。

六神、神煞和身体物类属于象义，不能据此确认真实人的疾病、死亡、犯罪、性关系等事实；灾害象不作真实灾害预报，财象不作交易保证。不输出没有计算规则支持的金额、概率、寿数、涨幅或精确时点。现实建议依据实际条件，不把解灾比喻改成医疗、伤人或动物代灾操作。
