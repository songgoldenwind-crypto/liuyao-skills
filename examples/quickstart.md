# 六爻开源版：三个可复现例子

以下日柱、月建和六次爻值都是演示输入，不代表真实当事人的起卦记录。执行命令的位置为仓库根目录或解压后的 WorkBuddy 单卡目录。`--lines` 始终按初爻到上爻；命令返回的 `chart.rows` 为上爻到初爻，阅读时不要反过来。

## 例一：求职卦先分岗位与录用

占问示例：“这次求职能否走到录用？”

```bash
python3 scripts/liuyao-intake.py \
  --lines 老阳 少阳 少阳 少阳 少阳 少阳 --day 甲子 --month 申
```

规范化爻值为 `9 7 7 7 7 7`；本卦乾为天，初爻动变天风姤，乾宫世在上爻，旬空戌亥。先核对上爻世爻父母戌土临空、四爻官鬼午火和初爻实际动变，再按求职的“岗位条件→联系面试→录用条件”逐层判断。这个盘不能只因官鬼爻出现就说已经录用。

## 例二：求财先看财与来源

占问示例：“这一笔求财能否实际到手？”

```bash
python3 scripts/liuyao-intake.py \
  --lines 少阳 少阳 少阴 老阳 少阳 少阴 --day 甲子 --month 申
```

规范化爻值为 `7 7 8 9 7 8`；本卦兑为泽，四爻动变水泽节。二爻妻财卯木为所求，四爻子孙亥水发动但在甲子日旬空戌亥之内，上爻父母未土持世。此例最多说明财爻与财源节点在哪里，以及动爻的后续条件；子孙“能生财”的名称本身不足以证明钱已到手。

## 例三：核对双动爻，避免把整张变卦当成六爻全动

占问示例：“别人发给我的卦盘，哪些爻真的动了？”

```bash
python3 scripts/liuyao-intake.py \
  --lines 老阴 少阳 少阴 老阳 少阳 少阴 --day 甲子 --month 申
```

规范化爻值为 `6 7 8 9 7 8`；本卦泽水困变水泽节。检查 `chart.rows[].actualChange`，只有初爻和四爻为 `true`。变卦其余四行只是完整卦形展示，不按真实变爻参加回头作用。读盘前还应核对本卦兑宫、世在初爻、应在四爻，以及旬空戌亥；任何一处与原始六次记录不符，先纠正卦盘再断。

若只有五次结果，脚本会拒绝输入；若只报起卦时间、未说明怎样成卦，也不能从这个时间自行补成铜钱六爻卦。使用真实公历时间时，先确认起卦地的钟表时间，再把 `--day 甲子 --month 申` 换成 `--at YYYY-MM-DDTHH:mm`，按排盘模块说明安装历法依赖。
