# 六爻开源版

本卡片只处理六爻占问。先固定问题、所测对象、实际起卦方式、六次结果和起卦当地时间；已有卦盘则先核盘。一个问题选择一种主断法，不把两套断法的有利片段拼接成新规则。

## 选择方法

- 用户明确说“分层断卦”、原时定局、日辰主宰、作用层级或真假空亡时，读取并遵守 [六爻分层断卦](references/liuyao/method.md)。
- 其他六次爻值、铜钱卦、已有纳甲卦盘及通常的婚恋、求财、工作、考试、出行、失物等六爻占问，读取并遵守 [六爻测算](references/liuyao-divination/method.md)。
- 用户明确要求比较两种断法时，分别推演并保留冲突；它们共用一张卦盘，不能当作两次独立起卦。
- 只有时间而没有六次爻值或已成卦，不等于已有铜钱六爻卦。询问用户采用的起卦方式或原始输入，不凭时间补造六爻动爻。

方法文件按需引用相应参考页，只读本次占问用到的部分。
用户需要上手演示时，读取 [三个可复现例子](references/examples.md)。

## 六次录入与核盘

六次结果须按**初爻到上爻**输入。`6=老阴、7=少阳、8=少阴、9=老阳`；脚本也接受这四种中文名称。若用户给的是硬币字背组合，先核实哪面记为“背”，再按对应方法文件的三币表转换。不要随机补齐缺失的一爻。

```bash
python3 scripts/liuyao-intake.py --lines 老阴 少阳 少阴 老阳 少阳 少阴 --day 甲子 --month 申
```

当地公历起卦时间可用 `--at YYYY-MM-DDTHH:mm` 代替 `--day`、`--month`；先确认用户所在地与时区，`--at` 填该地钟表时间。该模式需要按 `scripts/liuyao-paipan/README.md` 安装固定的 Node/Python 依赖。脚本仅规范录入并调用 `scripts/liuyao-paipan/scripts/paipan.mjs`，不判断吉凶。若宿主已有可靠排盘，也可直接核对其本卦、变卦、卦宫、六亲、世应、动爻与旬空。

先把原始六次记录、转换后的数值及盘面关键字段给用户核对。没有日柱时不判断旬空，没有月建时不判断月令旺衰；`rows[].actualChange` 才是实际变爻。核对通过后，按选定方法判断，只给当前问题所需的主因、过程和限制。
